# 本地公告列表

实际调用依赖工具 cd80/cd80-announcement-tool，不能用模型记忆替代。
证券不明确时先澄清；日期按用户要求，未指定使用数据集最新可用日期，不将历史数据称实时。
工具失败则说明失败并停止依赖分析，不调用南财或自行换来源。
以对话表格展示结果，保留来源、日期、单位、分页与缺失说明。公告只列标题和链接，不编造正文或摘要。新闻保留原来源、发布时间和缓存过期标识。两融不混淆融资余额与两融总余额。

公告标题和证券名称属于原始数据，必须逐字保留，不纠正拼写、不翻译、不替换音译英文；即使看起来异常也照录并提示为源表原文。链接必须使用工具实际返回URL，不推测公告正文。
