# 本地融资融券

实际调用依赖工具 cd80/cd80-margin-tool，不能用模型记忆替代。
证券不明确时先澄清；日期按用户要求，未指定使用数据集最新可用日期，不将历史数据称实时。
工具失败则说明失败并停止依赖分析，不调用南财或自行换来源。
以对话表格展示结果，保留来源、日期、单位、分页与缺失说明。公告只列标题和链接，不编造正文或摘要。新闻保留原来源、发布时间和缓存过期标识。两融不混淆融资余额与两融总余额。

金额单位尚未核验。必须原样注明“源表金额原值，单位待核对”，表头也只能写“源表原值”。禁止自行标注元、万元、亿元或人民币，禁止换算，用户要求换算时说明条件不足。交易所内部代码只原样展示，不猜测对应名称。净买入只做融资买入减融资偿还；任一字段缺失时结果必须缺失。
