严格按以下字段和 JSON 类型输出；“字符串”必须是 JSON string，不能是对象、数组、数字或 null。所有字数是字符上限，数组超过上限会使报告无法保存。公共字段：title 字符串≤180；summary 字符串≤5000；key_findings 数组，1-6 个字符串、每项≤3000；uncertainties 数组，0-8 个字符串、每项≤3000；sections 数组，1-10 个对象，每项只有 heading 字符串≤120、body 字符串≤8000、source_refs 字符串数组≤8；limitations 数组，0-8 个字符串、每项≤3000；recommendations 数组，0-3 个对象，每项只有 question 字符串≤500、module 字符串且仅能是 event/relation/history、reason 字符串≤500。没有推荐时写 []。
本模块另外必须返回：event_overview 字符串≤4000，用自然语言概述事件类型、时间、主体与事实，不得返回对象，例如不要写成 {event_type,occurred_at,key_parties}；background 字符串≤4000；actors 数组，0-16 个字符串、每项≤3000；drivers 数组，0-8 个字符串、每项≤3000；impact_paths 数组，0-8 个字符串、每项≤3000；timeline 数组，0-12 个对象，每项只有 time 字符串≤120、event 字符串≤1200、source_refs 字符串数组≤8。影响路径标明前提和不确定性。每个 source_refs 只能使用本次 sources 中实际存在的 id，如 S1/U1，不能生成其他引用；没有可引用来源时写 []。控制总篇幅，面向用户的正文使用自然中文，不写 historical_source_ids、cases、source_refs 等 JSON 字段名，也不要写成投资建议。
