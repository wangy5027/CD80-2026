# APP 技能池标准格式导出实现契约

2026-10-15。此文记录 APP 侧实现；产品共用规则见 [技能池标准格式导出](../integration/技能池标准格式导出.md)。

统一下载接口从已登录账号、当前详情卡的 `source`、`id`、`versionId` 调用 `agent_platform.standard_exports.export_standard(workbench_service, owner, source, asset_id, version_id='')`，返回 `(展示名称, ZIP 字节)`。函数只读已保存的精确版本，不触发模型、执行器、导入、验证或添加。路由负责认证、下载文件名和响应头。

| `source` | 身份检查与包内标准入口 | 可移植边界 |
| --- | --- | --- |
| `asset` | 账号内精确 APP 版本；`app.json` 为 `cd80.app-package/2`，包含代码、组件快照与原用例 | 可用现有 APP ZIP 预览、导入；接收者不继承验证、启用、文件授权或连接 |
| `community-app` | 仅未撤回发布快照的精确 `sourceVersionId`；同上 | 发布版本冻结，发布者撤回后也不可导出 |
| `builtin` | 固定的 Explore、策略工坊、应用工坊；`workspace.json` | 只说明平台工作区，不能作为独立 APP 导入 |
| `strategy` | 当前账号已保存策略；`strategy.json` 存规则与诊断详情，已有完整执行快照时另有 `strategy-package.json` 和 `source/` | 需平台策略工坊和重新确认行情、日期、资金；未有快照时不虚构源码；执行快照中的原始行情不导出 |
| `legacy-pipeline` | 当前账号旧版流程的精确 `id@version`；`application.json` | 旧版 `infinity-application/1`；依赖声明不包含依赖源码 |
| `preset` | 已注册的平台预置旧版流程；`application.json` | 同上 |
| `legacy-recipe` | 当前账号旧版研究模板；`application.json` | 同上，依赖旧版研究执行器 |
| `legacy-publication` | 未撤回的旧版共创原件；`application.json` | 同上；撤回后任何账号均不能导出 |

所有 ZIP 根目录都有 UTF-8 `readme.md`，列出展示名称、来源、精确版本或无版本声明、完整用途、调用方式、输入输出、流程、原任务用例、验证条件和真实可移植边界。现代 APP 逐步展开契约、源码、可读资源正文，并递归列出组件及其依赖的协议与资源正文；每一层保留组件身份和相对路径以免同名混淆。二进制保留在原包中并列路径、字节数与摘要。长文字不截断。历史格式保留既有真实原件，不转写成未经验证的现代 APP。

现代 APP ZIP 回导只允许把**未被步骤引用的根目录 `readme.md`** 当作导出说明，预览时明确提示该文档不会成为运行资源。若根 README 已被 `resourceFiles` 声明，则按真实资源冻结；若现代定义内嵌同名资源，JSON 内原件仍逐字节保留，根说明不覆盖它。其他未声明文件依旧拒绝。旧的纯 JSON、Python、ZIP 导入行为不变。

验收：`tests/test_standard_app_exports.py` 覆盖八种来源、跨账号与撤回、版本、完整 README、现代 ZIP 导入后未验证、README 同名资源、未验证与已完成策略边界；`tests/test_app_file_import.py` 和 `tests/test_standard_export_routes.py` 检查原导入和统一路由。当前仅完成代码与定向单测；正式浏览器下载及服务重启由集成验收记录负责。
