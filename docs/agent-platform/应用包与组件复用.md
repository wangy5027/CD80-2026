# 应用包与组件复用

状态：2026-10-14 本轮实施设计。目标对应 C02、C03、C04、C05；传统顺序应用与动态研究配方分别执行，共用可携带包的身份约定。

## 用户流程

用户可导入外部工具生成的应用 JSON，经过结构、依赖及敏感凭据检查后保存为个人独立应用；导入不执行。保存应用可以下载为包、另存副本，或以原定义为基础描述修改要求，生成新预览并确认执行。自然语言生成应用时可选择个人库已启用并有效验证的 Tool/Skill，应用固定引用其内容版本与配置，运行时重新检查准入。

## 协议与边界

- 包外层 `{format:"infinity-application",formatVersion:"1",kind:"pipeline",definition,dependencies,provenance}`。definition 保持 agent schemaVersion 1，工具和技能新增 capabilityRef；最多 8 个工具、8 个技能和 8 个顺序步骤。
- 本账号内部 capabilityRef 为 `{assetId,versionId,configurationId,sourceIdentity,contentDigest,kind}`。包内仅保留后三个跨账号身份字段；不导出连接、配置、密钥、运行输入、文件授权、运行结果或验证证据。来源记录仅是署名信息，不能授予权限或验证状态。
- 导入在个人库匹配 sourceIdentity、contentDigest 和 kind；多个匹配必须用 dependencyBindings 指定，缺失/禁用/未验证/配置过期均给明确错误。不会安装、启用或验证依赖。Skill正文在设计前快照，实际解释前再次准入。
- 个人Tool由能力库 invoke 执行，保留其隔离、连接、输出验证、取消与审计；应用代码不接触连接凭据。文件继续使用现有授权和摘要，能力输出文件复制到应用产物。
- 个人Skill的组件目录明确提供其精确工具依赖。应用的requiredTools必须连接这些相同assetId/versionId/configurationId的Tool，并在解释前实际安排执行；不能以同名内联代码替代或只挂载Skill文字而省略其工具依赖。生成、导入和每次运行均检查此关系。
- 固定流程支持Skill入口及入口同级references/目录下的UTF-8参考资料。规划与解释均读取同一精确版本；内容以能力包的contentDigest和文件索引SHA256锁定，读取时核对字节数和摘要。应用包继续只携带精确能力身份，接收者依赖包必须含相同资料；不从个人当前活动版本或宿主路径补读。
- 每个Skill最多16个参考文件、单文件最多12000字符，入口与参考合计最多36000字符；一个应用的全部Skill上下文最多60000字符。不截断方法资料；超限、非UTF-8、缺失或摘要变化明确阻断。运行loadedSkills记录capabilityRef及资源path/sha256/size，实际解释请求将参考正文作为方法资料传入。
- 固定流程不支持Skill脚本节点，声明skill.scripts的组件显示不可用原因，并阻止导入、生成和运行。用户可在动态研究中使用这些Skill；不能仅复制入口后声称脚本方法已执行。
- 新保存的导入包标记结构检查，不声明任何真实执行正确性。旧接口、应用定义与成功运行后保存不变；fork 使用独立ID。baseAgentRef 改编使用新ID，不覆盖来源。
- 成功保存后的改编与修订记录source来源和this_input_only验证范围；调用已有导入/复制应用后保存保留原来源，不把一次成功执行改写成对所有输入的验证。
- 从共创发布复制固定流程时，服务端内部source参数记录publication来源id与快照digest，并参与幂等指纹；HTTP请求体和包内provenance不能伪造该权威来源。后续改编保留sourceAgentRef，可回溯本人复制记录与原发布快照。

## API

所有接口要求当前账号会话；写接口使用已有 body.idempotencyKey。

| 接口 | 行为 |
| --- | --- |
| GET /desktop/api/agent-components | 本人Tool/Skill目录，精确引用、接口及不可用原因 |
| GET /desktop/api/agents/{id}/versions/{version}/export | 经过秘密检查的JSON包下载 |
| POST /desktop/api/agents/import | `{package,dependencyBindings?,name?,idempotencyKey}`，仅保存 |
| POST /desktop/api/agents/fork | `{agentRef,name?,idempotencyKey}`，仅保存独立副本 |
| POST /desktop/api/agent-runs | create模式新增baseAgentRef、capabilityRefs；不可与revisionOf混用 |

新导出dependencies保留componentId，并增加bindingId=`kind:componentId`（例如`tool:aggregate`、`skill:aggregate`）；dependencyBindings优先使用bindingId，值为`{assetId,versionId}`。Tool与Skill可以保留相同id，各自精确绑定。兼容无bindingId的旧包以及旧componentId绑定，但只有该id在全部个人引用组件中唯一时才接受旧键；有歧义返回409 application_dependency_ambiguous_binding，要求使用类型限定键。未使用或重复提供两种键的绑定拒绝。导入返回 `{agentRef,spec,personal:true,validationScope:"structure_only"}`。

## 验收

导出→另一账号导入→运行；导入和fork不调用模型或执行器；包不包含个人绑定和运行数据；错误包、秘密、跨账号、依赖缺失/歧义/停用及配置改变拒绝；幂等重放不重复保存；改编需重新预览；Tool与Skill精确锁贯穿生成、审批、执行。真实模型与真实金融业务验证单独记录。
