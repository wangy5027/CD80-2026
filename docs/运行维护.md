## 备份

金融库可用现有脚本的一致性备份接口，从项目根运行：
```powershell
.\.venv\Scripts\python.exe cd80-data-api/scripts/backup_db.py --output <新的备份文件绝对路径>
```
若修改过 CD80_DB_PATH，应同时传 --database <实际数据库路径>；该脚本默认路径不自动等同于当前环境变量。目标必须不存在，脚本用 .building 临时文件并执行 quick_check。

整个主站没有跨数据库原子热备工具。建议停止相关服务、确认无写入进程后，在仓库外受控位置保存：实际 DATA_DIR、配置文件、应用版本/依赖清单与金融库备份。上传字节、state.json、账号库、检查点、应用记录和产物应来自同一停机窗口。凭据备份单独限制访问，不进入 Git。

与其他任务共用的数据或服务，先协调维护窗口；本次文档整理不操作保护模块的文件与数据。

## 恢复建议（待演练）

1. 保留当前环境的完整备份，选新的隔离恢复目录，核对备份来源、时间与摘要。
2. 使用匹配代码和依赖；将配置中的路径指向恢复副本，不覆盖在线目录。
3. 对 SQLite 副本执行完整性检查，核对上传/产物字节与元数据。不要随意删除 WAL/SHM 文件来掩盖问题。
4. 启动隔离实例，验证登录、历史、上传下载、应用等待状态和金融库只读查询。验证重启中断行为，不重放历史运行。
5. 记录失败与缺失项；只有演练通过并获得切换授权后才安排正式切换。回退使用切换前的完整备份，避免混用不同时间的数据。

更换操作系统需重建虚拟环境和机器相关运行时缓存。关于其他模块的恢复限制应由其维护者确认，本页不作兼容承诺。
