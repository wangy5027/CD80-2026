# 整合产品设计

日期：2026-10-14。状态：开始实施。

以平台现有界面为准，统一登录和导航，三个应用独立使用，保留应用三推荐策略工坊的原有跳转。平台聊天、子任务、App/Tool/Skill 创作、验证启用、应用运行、文件、数据和共创功能继续可用。不新增自动跨应用编排。

Explore 保留事件两阶段解释、实体澄清及关联研究、历史材料对照、文件池、报告来源、连续记忆和恢复；历史对照不冒充行情回测。

策略工坊保留十种策略、规则改写、数据预检、诊断回测、图表、历史代码、保存和复跑。个人策略在统一应用页面展示，仍使用专用配置和回测页面；不新增正式收益报告或实盘交易。 2026-10-14按用户反馈修订：按原意定制策略只进行一轮集中需求对齐，回答后直接形成完整规则；用户确认后进入实现和校验，不继续逐轮追问。确实无法表达或缺少数据时明确结束并说明原因，不能擅改买卖条件。

应用工坊保持原推荐和组合范围。策略工坊只作为推荐跳转，不参与通用代码组合；完整且有权访问的原固定流程和本工坊生成应用可以作为来源，不自动加入全平台新 App、Explore、Tool/Skill 或社区资产。新应用保存为平台统一 App 草稿，保存无执行，未验证不可启用。未验证应用的创作来源资格与正式运行资格分开。

全新账号和空私人历史，保留公共金融数据及产品运行资源。测试使用独立数据目录。三个来源项目的账号、私人资产、上传和业务历史不迁移。

异常必须明确显示实际失败与下一步，刷新及重启不能自动重复业务执行；账号切换清理旧账号前端状态并拒绝迟到响应。
