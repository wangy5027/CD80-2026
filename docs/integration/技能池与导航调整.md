## 产品与验收要求

新任务的三个入口为 Explore、策略工坊、应用工坊；卡片与侧边栏分别共用 search、spark、grid 图标。侧边栏以默认关闭的“专有应用”折叠组容纳三个入口，可键盘展开并显示当前所在入口。

2026-10-14 后续调整：按用户截图移除侧边栏整个“智能体”分区，包括标题、加号、Ficagent 助手、编程专家和视频导演入口。项目与最近任务紧接主导航排列；此修改范围为侧边栏显示，不删除账号数据或助手运行配置。

技能池分为 Apps、Skills、Tools。点击“加入技能”打开模态框，下拉选择 APP、Skill 或 Tool，继续后进入对应手动编辑页面。取消关闭窗口并返回原按钮；编辑和保存错误保留当前输入。页面与长表单允许滚动，小屏不裁切底部操作。保存完成显示真实资产详情，可继续验证；不把保存视为执行或启用。

APP 是可复用 Pipeline，按顺序选择个人 Skill/Tool 的精确版本，填写步骤输入、Skill 执行目标与最终输出。允许调整顺序、移除步骤；只允许引用前序步骤。源版本无需先启用，服务端按当前账号冻结完整组件快照，App 必须完成自身验证才可启用。现有应用池与技能池 Apps 共用同一存储，不复制出第二套应用。

Skill 表单产生 Anthropic Agent Skills 的标准 SKILL.md：YAML 的 name、description，以及 Markdown 指令正文；可添加资源文件，标准原文与平台运行配置分开。Tool 填写完整 Claude 工具 JSON 定义，包含 name、description、input_schema，其他标准字段原样保存。执行实现独立填写 Python run(payload)；仅有接口定义时可保存，但必须明确缺少执行实现。平台暂不支持的定义字段或资源保留原件并显示兼容性问题，不静默删除，也不宣称可以执行。

参考：[Anthropic Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)、[工具定义](https://platform.claude.com/docs/en/agents-and-tools/tool-use/define-tools)。

## 技术契约

复用 /capabilities/drafts 创建草稿、/drafts/{id}/save 后台保存任务及原详情、验证、导出接口；失败重试保留草稿身份与幂等语义。保存结果未知时锁定表单，用同一提交核实；任务明确终止时先读回已保存版本，再决定是否允许新请求。Skill 支持额外标准 frontmatter JSON，转为合法 YAML 保留 metadata、license 等内容。Skill、Tool 使用 cd80.capability/1 平台包装，原件放入 original/，不将平台字段混入标准定义。

APP 通过既有 /asset-apps 接口保存 cd80.app/2，节点 componentRef 由后端解析为当前账号的完整快照。所有写入沿用登录账号鉴权和版本验证门禁；离开编辑页面或切换账号后中止请求并忽略迟到结果。导航内部 extensions 路由保留兼容，仅改变可见名称。

验证覆盖：表单与标准原件、步骤绑定、真实保存与未启用状态、缺少实现和不支持字段、冻结组件和账号隔离；浏览器检查首页图标、折叠、三类切换、模态框、长页滚动及实际保存。模型业务未改变，不以这些检查宣称新增模型质量结论。正式服务构建、重启及资源加载另行核对。
