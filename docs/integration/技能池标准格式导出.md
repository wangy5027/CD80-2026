# 技能池标准格式导出

日期：2026-10-15。状态：已实现，定向与浏览器下载验证通过，正式服务已重启。详见验收记录（本地资料，未随源码发布）。依据：用户要求 APP、Skill、Tool 详情弹窗右上角提供“标准格式导出”，通过浏览器下载与资产同名的 ZIP，并将完整详情写入包内 readme.md。

## 产品行为

三个分类的“我的”和“平台”目录详情共用同一按钮文字，置于右上角关闭按钮旁。点击导出当前正在查看的精确版本；未验证、未启用不影响导出。操作只读取内容，不执行、不验证、不添加个人副本，也不改变启用状态。下载期间避免重复点击，失败沿用全站错误提示。

ZIP 名称为展示名称加 .zip，保留中文，仅替换文件系统不允许的路径字符。浏览器正常下载，无需复制内容。切换详情或账号时，不能下载先前选择的资产。既有原件导出、纯标准 Skill 和完整实现导出的语义继续兼容。

## 包内容与边界

根目录必须有 UTF-8 readme.md，完整记录详情页面展示的名称、类别、版本、来源、说明、调用方式、输入输出、方法/流程、依赖、源码与资源、原用例及当前验证/运行条件。每类以其真实存在的数据生成，不为没有的数据编造内容。代码和可移植实现按既有 APP / Skill / Tool 规范随包提供；现有导入规范能恢复的资产需要覆盖往返测试。内置工作区或旧实现明确记载其宿主依赖和迁移边界，不能冒称独立代码已经完整导出。

README 是说明文件，不替代机器契约：APP 保留标准定义与组件快照；Skill 保留 SKILL.md、资源及必要平台适配；Tool 保留输入协议和实际执行实现/连接声明。测试用例保留独立预期，但不继承当前账号文件授权或验证、启用状态。原有同名 README 不应静默丢弃；实现方案需保留原件与源码完整性并在说明中解释位置。

个人内容按账号授权读取；官方/公开内容只读取该目录实际允许查看的精确版本，不为导出创建个人副本。导出不包含运行密钥、私人连接配置值或其他账号数据。

## 接口与实际包布局

认证 GET `/desktop/api/skill-pool/standard-export` 接收 `kind=app|skill|tool`、`source`、`id` 和 `versionId`，不接收客户端定义。本人/官方 Skill、Tool 要求精确版本；社区 releaseId 已冻结，versionId可空；APP各来源规则见[APP契约](../agent-platform/标准格式导出.md)。响应为ZIP附件，名称保留中文，替换非法路径字符并限制文件名长度，禁止缓存。

现代 APP 的根 app.json 为既有完整定义，readme.md 作为非运行说明回导；Skill/Tool 根 component.json 与 test-cases.json 保留完整实现及原例，standard-export.json 严格声明附属资料成员摘要。standard-skill/提供标准目录，standard-tool/提供调用协议，implementation/source/提供可读源文件；原README保留在精确快照与源码中。外层ZIP可直接回导，仍未验证未启用。纯标准Skill和原件旧导出行为不变。

## 验收条件

- 三类个人与平台详情右上角均有按钮；下载为同名 .zip，非 JSON 页面或文字预览。
- ZIP 根 readme.md 含详情完整文字与定义说明，长描述不截断；标准入口和源码/资源/原用例可读取。
- 个人、官方与公开版本鉴权和冻结版本正确；导出不执行、不改写正式资产。
- 当前可导入的标准包可再次解析保存，仍未验证、不自动启用；原有导出接口兼容。
- 构建、定向后端和浏览器下载检查通过后重启实际服务，核对健康与前端资源。
