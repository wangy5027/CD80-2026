# 整合技术规范

采用平台 Flask 应用工厂和 Vue 工作台为宿主，按原路由前缀注册 Explore、strategy_workshop、app_workshop。业务路由复用平台 Cookie 鉴权并在服务层检查 owner。公共账号、模型、搜索、新闻和错误处理以平台实现为主，应用专有行为通过适配补充。

Explore 自有 SQLite、提示词和 Skills 完整保留；对接平台 Provider 的追踪和错误码，不覆盖平台预算及取消逻辑。进程关闭中断活动运行，重启按原语义标记 interrupted。

策略工坊保存自有会话、运行、不可变策略快照和个人策略，统一应用页面聚合该目录但不转换其执行语义。固定策略受控子进程及自定义 WASI 路径保持原校验。复制公共行情源库、派生库与映射，修正为最终版内路径。

2026-10-14 单轮对齐修订：`customization` 仍使用原接口。首次缺必要条件可返回 `needs_clarification`；旧/新会话在此状态收到非空回答后，后端将上轮问题、建议、摘要及本次回答作为 `alignmentContext` 传入改写器，置 `alignmentCompleted=true`。模型最多三次内部结构/语义收敛尝试；仍追问则终止为 `alignment_incomplete`，`questions=[]`、阻碍存于 `alignmentIssues`，不得产生规则摘要、源码或可用候选。外源数据缺口优先保持 `unsupported_data`。终止态拒绝继续提交，必须通过已有返回/重新描述流程重开；空回答在模型调用前拒绝，幂等缓存先于终止判断。已完成对齐的主动修订也不再开放追问；直接规则就绪的旧会话继续原确认流程。`rules_ready` 仍需用户明确确认同一 `customizationId/rulesDigest`，真实 WASI 校验通过后才可采用。最终轮连续三次结构或表达式无效返回 `rewrite_finalization_failed`，原状态保留，可重试同一回答。改写技能版本升为 `strategy-rewrite-1.1.0`，旧记录版本不改写。

应用工坊使用自己的会话、幂等记录和来源索引；通过平台 AssetApps 保存 cd80.app/2 新资产。原 AgentSpec 可作为生成中间表示，通过完整 legacy 适配转换，源文件授权不继承。来源索引关联 owner、工坊会话、新 App ID 和原完整定义；组合/推荐从服务器重新校验。保存采用稳定幂等请求，跨表失败可恢复，不宣称跨库原子事务。后续组合必须取与当前平台版本一致的实现，禁止以过期侧存储覆盖新版本。

前端保留平台全部现有视图，新增三个工作区并兼容 hash 恢复。应用目录聚合策略应用；应用三保存后导航至新版应用详情，推荐旧固定流程仍用兼容面板。统一公共 API 封装，隔离不同账号草稿与轮询。

正式 DATA_DIR 独立为空，验收 DATA_DIR 独立；金融库及运行时属于公共资源，不能整体复制来源 data。后端凭据私有注入。默认仅监听 localhost，不扩大部署范围。Mac 重新安装依赖并校验 WASI；正式启动和验收启动不可共享私人历史。

平台 MCP 连接凭据的 Mac 兼容修复沿用原有准入、请求头白名单、DNS/TLS 校验和不可明文入库原则。Windows 继续使用 DPAPI；Mac/Linux 使用锁定版本的 `cryptography` Fernet 认证加密。每个实例只在自身 `DATA_DIR` 创建随机密钥文件，创建时采用排他打开、`0600` 权限和禁止符号链接；再次读取时核对文件类型、归属和权限。密钥丢失、权限异常、密文损坏或版本不符均返回明确失败，不自动重建旧密钥或把解密失败的凭据覆盖为新值。数据库只保存带版本标记的加密令牌。修复限定于凭据保护，不放宽连接发现、工具调用或应用启用门槛。

实现将 `cryptography==50.0.2` 固定在根 `requirements.txt`，Mac 密钥保存为实例 `DATA_DIR/.capability-mcp-key-v1`，应用只在尚无任何已存凭据时允许新建密钥。已有密文覆盖前先解密旧值；密钥丢失后新建另一连接也不能重建密钥并使旧记录失效。对密钥权限、符号链接、丢失、坏密文和非明文入库的 Mac 定向测试与原平台凭据测试均通过；完整能力库文件 28 项通过。测试密钥只在最终版 `data/capability-validation/` 下临时创建并清理。

执行顺序：平台基础与环境→模块独立适配→共享入口/目录→构建/回归→真实链路/浏览器→文档交付。公共入口由主代理维护；模块实现者只修改分配目录，接口变化先协调。

## 2026-10-15 滚动布局修复

应用工坊、策略工坊与共创各自使用有界滚动宿主，不能依赖overflow隐藏的主工作台滚动。数据管理弹窗以flex分配正文/错误/操作区；Explore窄屏文件池允许外层滚动并保留内部长正文滚动。桌面及小屏验证见本轮验收（本地资料，未随源码发布）。

## 2026-10-15 全站错误提示统一

按用户明确要求，用户界面的请求、上传/格式、模型、流式对话、执行及历史失败提示统一显示“当前网络连接失败”。这是产品展示文案，不改变实际错误类型、状态码、重试/取消语义、验证门槛或内部诊断记录。错误详情、错误码和堆栈不再从弹窗、提示条、目录错误、步骤失败及模型详情泄露至用户页面；正常输出、填写说明、未验证状态和授权/确认流程保留。共享展示函数位于 `frontend/src/shared/userFacingError.js`，各错误渲染位置引用相同文案，不能只在请求层处理而漏掉已保存历史或本地格式检查。验收覆盖实际错误文件上传、接口失败、流式失败、历史错误和成功内容保留，最终构建并重启正式服务。
