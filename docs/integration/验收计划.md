# 整合验收计划

1. 平台相关及全量自动化、前端测试和构建，记录实际失败、跳过及来源既有问题。
2. Explore 默认三流程、事件两阶段、模型与记忆、文件、取消重试、幂等及恢复。
3. 策略推荐、自定义、预检、诊断回测、图表指标、保存、不可变快照复跑及账号隔离。
4. 应用工坊原来源集合、推荐跳转、真实实现组合、新版 App 保存零执行、重复保存、验证启用、后续来源复用和账号隔离。
5. 浏览器统一登录、三个入口、应用目录、返回/刷新、双账号隔离和平台核心路径。
6. 独立验收数据目录执行真实模型、搜索/新闻、行情、WASI 链路。失败保留证据，不以替身冒充真实。
7. 正式空数据实例启动；检查进程路径、健康、前端资源、业务初始空历史。核对来源摘要，交付启动/停止/重启及限制说明。

详细结果写入本目录验收记录。每条结论注明环境、实际版本或文件摘要、用例和结果，未经运行不写通过。
