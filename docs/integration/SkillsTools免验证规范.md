# Skills/Tools 可信来源免验证规范

状态：2026-10-15 后端已实现并通过隔离回归；正式服务和浏览器加载由整合验收分别记录。适用于能力库的独立 Skill/Tool；App 的验证门槛不变。

## 用户行为与边界

平台官方已有的精确版本，以及其他用户主动公开发布的不可变精确版本，添加到当前账号后无需再做个人双用例验证。添加仍只是保存：默认未启用、不执行、不读取文件，也不继承发布者的连接、凭据或输入。用户须主动启用，启用及每次调用仍检查包的完整性、当前运行配置、权限、连接、文件授权、精确 Tool 依赖及执行隔离。缺连接、缺依赖、无实现、危险权限或已退休能力不能因免验证而绕过。

个人上传、手写、模型新生成以及对来源内容编辑后的新版本，仍按 `original_and_new` 完成真实验证。仅靠上传包 `manifest.source` 声称官方或公开来源不能得到免验证资格。免验证不写入 `passed` verification，不把未经执行的副本称为“已验证”。

## 服务端信任与版本语义

可信准入授予只在官方副本和社区发布副本的服务端路径发生。授予记录绑定来源类别、不可变官方 `publicAssetId/publicVersionId` 或社区 `releaseId`、以及复制的 `contentDigest`；对依赖闭包中的每个独立 Tool 精确版本分别授予。已有旧副本可由服务器保存的资产 provenance 与官方版本/社区发布快照逐字节内容摘要核对后识别，不读取上传清单中的来源声明作为证明。重复添加同一精确版本应复用、补齐依赖并确保其准入来源；修改资产时新 `versionId` 未经可信复制不继承旧版本资格。

社区撤回只禁止后续查看和复制；撤回前完成的个人副本仍保留其冻结内容的准入。若来源记录或精确摘要无法核实，按个人需验证处理；不能因 `sourceIdentity`、名称或当前公共最新版相同而升级。官方目录内容必须通过维护者发布检查；公共目录版本本身显示官方准入状态，但个人调用必须先显式复制。社区作者自己创建的原个人版本仍依照其真实验证证据，不能因自己发布过而自动免验证。

`GET /desktop/api/capabilities/assets` 个人项、资产详情、版本列表与精确版本详情返回 `admission: {mode,source,validationRequired}`。`mode` 为 `trusted_release` 或 `validation_required`；`source` 为 `official`、`community` 或 `null`；`validationRequired` 为布尔值。官方公共版本详情也返回官方策略。有效可信来源且没有静态/当前配置问题、尚无个人真实验证时 `readiness=ready`；有有效真实验证仍可显示 `verified`。`blocked`、`needs_configuration` 优先于二者。列表资产的字段对应当前展示版本（已启用版本优先），执行选择的权威是精确版本返回值。前端将 `ready` 显示为“免验证 · 可启用”，不误写“验证通过”。

## 实现检查点

`check` 与 `refresh_readiness` 计算准入；`admit` 在普通调用中要求有效验证或可信准入，试用继续只绕过验证、不绕过运行安全；`update_asset` 主动启用同样放行可信准入。Skill 依赖递归逐个准入。社区发布仍只接受已真实验证版本及完整依赖，不允许通过复制来的免验证状态直接二次发布，以免放大错误来源或绕开作者审阅。App 自身验证、组件快照运行、文件/连接/权限检查不因该策略放宽。

官方旧 `prepare` 路径不再执行样例制造个人 passed 记录作为启用前提；保留兼容入口但按纯复制闭包返回，连接或环境缺口由主动启用时说明。前端优先使用 `ensureOwned` 纯添加路径。

## 验收

隔离账号和临时数据覆盖：官方/社区根与依赖精确复制即 `ready`、默认停用、主动启用和真实 WASI 调用；旧副本识别；重复/跨键添加；编辑新版本重归需验证；伪造来源上传不授予；社区撤回后旧副本保留；缺实现/连接/权限/依赖仍阻断；公开作者原稿和 App 验证保持原门槛。旧直接复制入口也阻止从已下架官方源新建副本。相关后端回归分批 32、17、63 项通过，加上此定向修复后专项 6 项通过，其中新增 1 项；合计 113 个不同测试，未把重复重跑计入。自动化不使用正式账号或真实外部上游。另有官方历史日线 App 实例（本地资料，未随源码发布）在独立账号真实调用本机只读金融服务和 GLM-5.3-Flash，证明组件免个人验证而 App 仍经双例验证、启用和主对话调用。实现、自动化、真实模型、浏览器与正式服务验证分开记录。
