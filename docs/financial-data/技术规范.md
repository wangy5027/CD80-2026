# 金融数据网站接入技术规范

状态：2026-10-13 代码现状整理；接口或数据变化时同步维护。

同源 /desktop/api/financial-data 由 Flask 鉴权后代理到本机 /api/v1。capabilities 返回 canRead/canWrite；可写要求管理密钥与用户 UUID 白名单共同成立，不按邮箱匹配。读取优先使用 read key，再回退 admin key。

代理仅接受本机 HTTP origin，禁重定向并关闭环境代理；表名限定 cd80_*。成功 JSON 原样传递，错误转换为主站 error。POST /query 是读取，POST /rows、/rows/batch 与 PATCH/DELETE 行接口是写入。

字段、筛选、分页、事务和行主键规则以 [数据契约](../../cd80-data-api/docs/CONTRACT.md)、[OpenAPI](../../cd80-data-api/docs/openapi.json)、[数据目录](../../cd80-data-api/docs/data_catalog.json) 为准，不复制字段清单。用户页面说明见 [数据管理使用说明](数据管理使用说明.md)。

联合启动使用根 Windows .venv，默认主站 8894/数据服务 8897；数据模板旧默认的差异见配置说明。

## 2026-10-15 弹窗长内容滚动

弹窗改为纵向flex和动态视口限高，正文、长错误提示可独立滚动，底部操作区不被挤出；只在open时启用flex，保留关闭语义。390×400长详情与无效数量错误验证通过，接口与数据规则未改。见整合专项验收（本地资料，未随源码发布）。

## 2026-10-15 目录读取扩展

新增同源 `GET /desktop/api/financial-data/catalog` 转发到数据服务 `GET /api/v1/catalog`，沿用登录权限、本机代理和服务端读取密钥；旧 `/tables` 合同不变。目录仅遍历登记且物理存在的 `cd80_*` 表，字段与实际 schema 交叉核对。主日期按业务白名单从真实值归一化读取，保留日/月粒度；来源只显示文件名。缓存无持久写入，并随本库修改失效。具体结构及边界见[目录接口](../../cd80-data-api/docs/CATALOG.md)。静态 data_catalog.json 是导入历史说明，不作为新目录实时事实来源。

`cd80_ci_index_member` 在库内英文 title 被误标为 Shenwan；根据 [Tushare 官方 ci_index_member 文档](https://tushare.pro/document/2?doc_id=373)和本地 CI 代码，页面名称及展示摘要使用“中信行业成分”。仅修正展示，不改写原始元数据或金融记录。

## 2026-10-15 私人数据文件接入

“我的数据文件”调用已登录工作台的 `POST /desktop/api/files`，multipart 增加 `purpose=data`。该分支按实际字节校验单文件不超过 10×1024×1024 字节，允许 `.csv`、`.tsv`、`.json`、`.xlsx`；文本需可按 UTF-8 或 GB18030 解码，JSON 必须有效，XLSX 须通过有界 ZIP 检查及只读工作簿解析。扩展名或 MIME 不单独构成通过依据。普通文件上传不传 `purpose`，维持原 30 MiB 与原附件规则。

成功文件在账号 `state.files` 中保留原 ID 和原始字节，增加 `source: "data_management"` 与有界 `dataInfo`（`format`、`columns`、`sheets`、`preview`、`previewRows`、`truncated`；文本文件另含 `encoding`）。列、单元格、预览行数受限时标记截断，不把样本冒充全量结果。相同账号、项目、原文件名和字节内容重复上传时复用 ID；普通文件被数据入口再次上传时只提升元数据标签，不改写原文件。跨账号读取、下载、删除及引用均由原文件池归属鉴权。

官方数据目录仍通过独立的金融数据服务读取本地 SQLite；私人文件的上传和删除不调用官方表的写接口。主问答及历史按文件 ID 重新确认当前账号归属、内容存在及 SHA256，一次只附带有界的真实数据预览；原文件留给获授权的工具使用。细节以[个人数据文件设计](个人数据文件.md)和[工作台技术规范](../workbench/技术规范.md)为准。
