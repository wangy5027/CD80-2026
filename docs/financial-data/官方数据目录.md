# 官方本地数据目录

日期：2026-10-15。状态：实现完成，隔离测试与浏览器验证通过；正式服务验证见本次验收。依据：用户要求在数据管理中查看官方提供的数据源、已有表、主要列、主要日期范围及表来源，数据提供方统一标注 Tushare；展示内容只取当前本地 SQLite 已有数据。

## 产品行为

数据管理首页突出“官方数据源 · Tushare”，说明当前可用内容是平台已收录的本地数据。用户可搜索、浏览已有表；每张表展示中文用途、真实表名、主要列及含义、主要日期范围与对应日期字段/口径、原始来源文件名。点击表后可查看完整字段、日期信息及既有数据记录，原有筛选、分页和读写权限保持。

时间范围以当前本地表中实际存在的日期为准，不用官方接口理论覆盖范围或旧静态目录推断。交易日、公告日、报告期、上市日等口径明确分开，不汇总成误导性的全库覆盖时间。无日期列、空表或缺有效日期分别说明；特殊精度（如月份）如实表达，不猜测交易日。数据提供方按用户要求统一为Tushare；原始文件/接口表名是表级来源说明，不承诺本轮在线同步或实时覆盖。

## 技术约束

数据服务从已配置SQLite的登记表与实际sqlite_master/PRAGMA交集读取目录，过滤不存在的表/字段和内部账号、审计等表；不扫描其他业务数据库。现有导入元数据仅用于字段说明、来源文件与导入时间，不能把历史JSON里的统计当作当前事实。主要列从实际存在的字段中选择，完整schema仍可查。

日期范围采用只读、参数边界明确的查询，从本地真实值计算；优先明确的主日期字段，对多个日期保留字段口径。需要有界执行和缓存，避免每次页面加载扫描全部大表；缓存随本库修改失效。异常不伪造范围，不改写正式数据、索引或原记录。

浏览器仅通过现有登录鉴权和本机代理读取；不传数据库路径、SQL、管理密钥。UI只显示来源文件名，不暴露机器绝对路径。接口具体字段由本轮后端与前端合同同步，设计不另造执行器。
