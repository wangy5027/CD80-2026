# 金融数据网站接入产品设计

状态：2026-10-13 对现有功能的现状整理，不是补写的历史审批。新需求需明确确认后更新。

已登录用户查看共享比赛数据的表、字段和记录，按条件筛选并翻页。具备服务端写权限的用户可以新增、编辑和明确确认删除；界面提供可读/可写状态。

流程：登录 → 数据管理 → 选表/筛选 → 查看详情；有权限时进入新增或编辑，成功后刷新；删除先确认。浏览器不接收管理密钥，写权限不能只靠前端按钮判断。

验收条件：无登录拒绝；普通用户只读；授权用户 CRUD 持久化；空文本与 NULL 区分；代码和日期保留文本格式；分页可遍历大表；写入与审计一致。写测试使用临时库，不修改正式比赛记录。

## 2026-10-15 官方本地数据目录

数据管理增加“官方数据源 · Tushare”：可搜索本机已有数据表并查看主要列、日期范围及业务口径、原始导入文件和记录数量。所有目录内容取当前配置的本地 SQLite；不请求上游实时数据。无业务日期的表明确说明，不将月度日期伪装为每日覆盖。目录与既有选表、记录筛选、分页联动，原读写权限保持。详细约定见[官方数据目录](官方数据目录.md)。

## 2026-10-15 我的数据文件

登录用户可在数据管理的独立区域上传、查看、下载及删除自己的数据文件。该区域与只读的官方 Tushare 数据目录分开；私人文件不进入官方表，也不要求官方数据库写入权限。页面在选文件前说明支持 CSV、TSV、JSON、XLSX 和单文件 10 MiB 上限；失败按全站统一反馈展示。

上传成功后，文件保留在账号现有文件池中。主页面问答“添加文件”可选择“数据管理中的文件”作为本次附件，其他复用文件池的输入也可按同一 ID 引用。未选择的文件不会自动进入问答；删除后不能在新请求中再次引用原文件。具体流程与权限边界见[个人数据文件与跨页引用](个人数据文件.md)。
