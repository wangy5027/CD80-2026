# 数据管理使用说明

当前 Windows 入口：项目根双击 start-local.cmd；网站 http://127.0.0.1:8894/desktop/，数据接口 http://127.0.0.1:8897/docs。完整步骤见 [Windows 指南](../../LOCAL-WINDOWS.md)。

使用自己的本站账号登录，打开“数据管理”。选择表，添加筛选条件并应用，打开记录查看详情。界面显示可编辑时可新增、编辑或确认删除；保存后刷新核对结果。没有权限请由维护者配置当前用户 ID，不通过共享账号获取权限。

写入要求管理密钥及用户 UUID 白名单，均由后端读取；浏览器不填写密钥。当前比赛库默认在 cd80-data-api/data/cd80.sqlite3，配置后可能变化。原始导入为37张表、19,274,362条记录；实时数量以接口为准。

编辑时保留代码前导零及日期原格式，空文本与 NULL 不等价。新增、修改和删除作用于共享数据库并记录审计，不用真实比赛记录做练习写入。单个记录删除需要明确确认。

接口见 [独立数据服务](../../cd80-data-api/README.md)。旧账号迁移资料保留在 历史归档（本地资料，未随源码发布），不作为通用登录指南。

## 查看官方数据源

当前 Mac 入口为 http://127.0.0.1:8894/desktop/。登录后进入“数据管理”，页面上方“官方数据源 · Tushare”列出本机 SQLite 现有表；可按表名、中文名称或主要字段搜索，点击目录卡片或下拉列表选表。详情展示主要列及含义、记录数、来源文件名、实际日期首末值与日期口径。交易日期、报告期、上市/成立日不是同一种时间口径；月度数据只显示到月份，无适用日期的表会明确说明。

点击“查看数据记录”进入下方列表，继续使用原有筛选、分页和完整记录弹窗。“刷新数据”同时更新目录信息，保留当前选表及筛选。手机目录可单独滚动，页面正文也可继续向下浏览。Tushare 为统一展示的数据提供方，本页面只读取本地已有数据，不在线同步行情。

## 上传与引用我的数据文件

在“数据管理”的“我的数据文件”区域选择本机文件并上传。页面会先说明可用格式为 CSV、TSV、JSON、Excel `.xlsx`，单个文件不能超过 10 MiB；服务端还会核对文件实际内容。已上传文件只属于当前账号，可在列表中查看、下载和删除。上传失败按全站统一反馈显示，上传条件在操作前即可看到。

要在主页面问答中使用它，点击输入框的“添加文件”，选择“数据管理中的文件”，勾选本次需要的文件后再发送消息。聊天只读取有限的文件内容预览，并明确标出截断；需要完整数据处理的获授权工具按原文件引用。未勾选的文件不会进入本次问答。私人文件与上方 Tushare 官方本地目录相互独立，不会写入官方金融表；原有官方表浏览、筛选和授权写入方式不变。详细约定见[个人数据文件设计](个人数据文件.md)。
