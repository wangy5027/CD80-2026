# 个人数据文件与跨页引用

日期：2026-10-15。状态：实现完成；专项测试、浏览器和正式服务验证通过。依据：用户要求数据管理可上传本地数据，限制格式、单文件不超过10MB，上传后其他页面（尤其主问答）可选择已有文件引用。

## 产品设计

数据管理顶部增加“我的数据文件”，与官方Tushare目录分区显示。私人文件属于当前账号，展示文件名、格式、大小、上传时间，支持上传、下载、删除和在问答中引用。独立于官方目录的可用性；不要求官方数据写权限，也不把私人文件写入官方SQLite表。文件与现有文件池复用同一ID，刷新后仍保留；主输入框“添加文件”明确列出“数据管理中的文件”，勾选后作为本次附件发送。其它已复用文件池的App输入选择仍可按ID引用。

本轮默认允许CSV、TSV、JSON、Excel(.xlsx)，单文件上限10×1024×1024字节。允许用户追加格式偏好，但未确认前不支持任意脚本、可执行文件或压缩包。前端选择器与提交前检查、服务端硬限制同时生效。类型以扩展名及实际内容校验，不能仅信MIME；上传数据不会执行。上传条件事先展示；错误展示沿用全站统一文案。

## 技术规范

复用工作台 `POST /desktop/api/files`，multipart增加 `purpose=data`，服务端以该分支执行数据类型/10MiB校验；无purpose的既有通用文件入口保持原规则。返回文件元数据增加 `source: "data_management"` 和有界 `dataInfo`（格式、预览及列/工作表信息）；用户在现有state.files中访问。相同账号/项目/名字/内容已存在时复用原ID并提升数据标签，不能覆盖字节或跨账号复用。数据文件列表由当前账号state按source筛选，不另造共享池。

CSV/TSV采用受控解码和结构化有界预览，JSON检查格式，XLSX采用只读解析并限制ZIP展开量、成员数量，拒绝不匹配或不支持的内容。数据概要必须明确“预览”及截断，不将样本解释成全量统计。完整原始文件保留，用于下载和已授权工具执行。

主问答沿用fileIds鉴权，只将本轮选择的数据文件的有界概要送入上下文；历史按同样规则重建。数据文件不再受旧文本附件180KB上限拒绝，不能把10MB完整内容直接塞进prompt。子任务可把当前授权数据文件作为最多10MiB输入保存并使用有界预览；输出原4MiB限制不变。能力库file_grants对数据管理来源支持单文件10MiB，执行器现有总输入预算仍生效。现有普通文件限制保持。任何读取都验证当前账号文件归属及内容存在，文件内容作为不可信参考资料处理。

接口鉴权、删除、下载及账号切换的迟到响应规则复用当前实现。未选文件不自动进入模型，删除后新发送不能再引用该上传ID；已完成任务中的历史工件快照沿用现有留存规则，不随删除上传文件级联清除。上传原文件不修改正式金融库，不外发到第三方存储。

## 验收

- 隔离账号真实multipart覆盖格式/大小边界、伪装与畸形内容、重复上传/刷新持久、跨账号读取/删除/聊天拒绝。
- 所有允许格式可上传，CSV和Excel实际内容进入受控问答上下文；大于旧180KB、4MiB的合法数据文件仍能被引用，预览明确有界。
- 浏览器完成数据管理上传、主输入框已有数据选择、发问附件ID绑定、下载/删除，手机可滚动，无越权或正式数据写入。
- 相关回归、生产构建后重启正式前后端，核对健康及实时资源；文档记录精确测试范围，不把隔离模型替身当作真实外部模型验收。

验收结果：前端387项、上传/聊天26项、数据执行5项、相关回归49项及代理10项通过；浏览器6组通过，正式服务已重启并核对入口资源。详见完整验收与模型边界（本地资料，未随源码发布）。
