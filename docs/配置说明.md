# 配置说明

状态：2026-10-13 现状整理。本次只补说明，不修改 .env、模板或代码，也不列出私人配置值。Tools/Skills专项配置见文末及 [内置目录说明](capability-library/内置工具与Skill接入.md)。

## 加载顺序

联合启动：start-local.cmd 使用根 .venv → start_all.py 读取 cd80-data-api/.env（override=False）→ 显式设置传给子进程的 CD80_DB_PATH 绝对路径和 CD80_DATA_API_URL → main.py 再读取根 .env（override=False）。已有进程环境变量先于两份 .env，数据服务 .env 先加载的同名字段也不会被根 .env 覆盖。

联合启动的 --website-port 和 --api-port 明确决定监听端口，并覆盖传给主站的代理地址。仅编辑模板不改变现有 .env；修改 .env 后要重启相关进程。

直接运行 main.py 只负责根 .env，不自动按联合启动流程载入数据服务 .env。独立 uvicorn 应显式提供 --env-file。

## Tools / Skills 与MCP

SKILLS_DIR默认项目skills目录；SFC_TOKEN或SFC_KEY_FILE仅在后端配置，SFC_REQUEST_TIMEOUT默认20秒。原内置目录与个人库是不同入口。CAPABILITY_MCP_POLICY_FILE指向维护者审核的本机JSON策略文件，相对路径以项目根解释；默认空，不表示自动信任远程工具。

策略按endpoint指定maintainer、evidence和完整工具定义摘要。具体格式与限制见 第一版记录（本地资料，未随源码发布）。连接凭据由个人私密接口写入、DPAPI保护，不写进策略、前端或导出。更改策略需重启并重新发现/验证；仅声明只读不足以执行。
