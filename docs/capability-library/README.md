## 当前入口和资源位置

后端为 backend/app/modules/capability_library/；前端为 frontend/src/modules/workbench/components/CapabilityLibraryPanel.vue 与 capabilityApi.js。工作台“扩展”提供独立 Skills / Tools 目录，旧内置目录保留在折叠区。

数据在 DATA_DIR/capability-library/capabilities.sqlite3；实际使用两张通用表，不使用旧设计里的独立 assets/versions 等物理表。会话锁在既有工作台任务中；应用消费新能力的编排改造不在第一版范围。

**examples/ 是运行依赖而不只是文档示例。** 后端和测试按固定路径读取其中公共样例，不能为整理文档移动或修改。第一版文档整理未改机器契约及标准Skill目录；2026-10-14统一资产实施已同步本模块Schema/OpenAPI，具体变更见上方组件契约。

## 产品与执行边界

导入不执行、不安装依赖；保存、验证和启用分别发生。配置/凭据变化使证据失效，旧会话锁定版本，禁用优先于历史引用。外部写入、未知权限、不支持的必要执行能力不允许正式调用。

生成代码使用 WASI；MCP 仅允许经维护者审核的只读工具，readOnlyHint 不是授权证据。保留原件与完整包分别导出，凭据和历史私密数据不导出。失败不自动换工具、修代码或重放。

更改本模块后同步 总项目状态（本地资料，未随源码发布）。字段以现有机器契约为依据，代码与文档不一致应登记问题，不仅凭 Schema 校验就判定可运行。
