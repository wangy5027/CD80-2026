# 能力库实施与验收

本文件保留开发阶段的交付顺序和验收矩阵。第一版已实现，已执行的测试和实际限制见 实现与验收记录（本地资料，未随源码发布）；本矩阵列出的场景不应仅凭文档存在就视为逐项验收通过。

## 分阶段交付

| 阶段 | 工作 | 完成条件 |
| --- | --- | --- |
| A 资产基础 | 新模块、存储、原件、导入检查、状态与身份 | 上传不执行，同内容去重、用户隔离、危险包拒绝 |
| B 验证与执行 | WASI 包挂载、统一准入、样例验证、凭据、MCP | blocked 无执行路径，实际样例证据和只读 MCP 成功 |
| C 管理产品 | 双库页面、详情、公共复制、编辑、重导入、导出 | 用户可独立完成完整生命周期，无依赖推荐或绑定入口 |
| D 对话接入 | 候选目录、按需资源、版本锁、消息事件、沉淀草稿 | 手动和自动调用可追踪，不绕过准入 |
| E 回归交付 | 原工作台及应用回归、异常恢复、文档同步 | 下列用例通过；旧业务行为和用户数据保留 |

每阶段独立可审查；新表和接口完成前不将新菜单切到正式使用。数据库迁移先备份，在临时库验收后才处理真实用户数据；不借测试修改比赛数据。

## 验收矩阵

| ID | 场景与操作 | 预期与证据 |
| --- | --- | --- |
| AC01 | 导入纯文本 Skill 及 references | 原件摘要一致；检查通过；测试对话读取资料；用户确认后方可启用 |
| AC02 | 导入依赖不存在的 Skill | needs_configuration；只列缺项；无推荐、替代或绑定按钮 |
| AC03 | 补齐工具但不重导入 Skill | Skill 不自动转可用；主动重导入后精确复查 |
| AC04 | 相同包重导入、新内容重导入 | 相同 versionId 复查；新内容新 versionId；旧 activeVersionId 不自动替换 |
| AC05 | 同名不同来源、跨账号相同包 | 同名可区分；个人范围去重；不能看到其他账号资产 |
| AC06 | Python 十进制求和样例 0.10+0.20 | 隔离结果 content.total 为 0.30，输出结构和结果均通过 |
| AC07 | Python 尝试网络、宿主文件或覆盖输入 | 运行器拒绝；无宿主改动，不能退回宿主 Python |
| AC08 | 上传包带安装脚本、导入副作用代码 | 解析阶段无执行、无联网安装；报告必要执行要求 |
| AC09 | Bash、Node、特定宿主 hook 为必要步骤 | blocked，试运行与正式调用都403/422；原文件未改 |
| AC10 | 上传路径穿越、链接、重复路径、压缩炸弹 | 安全拒绝，不写出隔离目录，不展开恶意内容 |
| AC11 | 仅 OpenAI 或 Claude 工具定义，无实现 | 可保留定义，待配置或不支持；不能显示可调用 |
| AC12 | 同一支持子集定义的两平台导入导出 | 参数类型与约束保持；未知语义阻断，原件不被覆盖 |
| AC13 | 远程 MCP 上传描述 | 不联网；主动 discover 才发现；不调用 tools/call |
| AC14 | 平台可控只读 MCP 完整接入 | 发现、导入、检查、样例、启用和调用均有记录 |
| AC15 | MCP 只声称 readOnly，但无准入证据 | blocked: permission_unknown，不能用用户勾选放行 |
| AC16 | 写入型 Tool 伪装只读或由旧接口调用 | 所有入口拒绝；模型/HTTP/试运行/旧端点均不能绕过 |
| AC17 | MCP schema 改变、重定向、DNS 指向私网 | 失效或拒绝；不携带凭据访问新目标 |
| AC18 | MCP 返回 isError 或不支持结果类型 | 明确失败，不因 HTTP 200 显示成功 |
| AC19 | 用户A使用用户B资产、连接、文件、下载 | 404或拒绝；日志无B数据 |
| AC20 | 凭据配置、轮换、导出 | GET、模型和导出无密钥；轮换使旧证据失效 |
| AC21 | 文件按次选择，下一轮不选择 | 不继承授权；必要文件缺失时暂停告知 |
| AC22 | 手选 Skill、手选 Tool、明确调用 Tool | 分别记录加载、候选、实际调用；不能以普通文字冒充 |
| AC23 | 首次使用V1，启用V2后继续旧对话 | 仍锁V1；显式确认切换才变更，陈旧 taskRevision 拒绝 |
| AC24 | 旧对话引用版本被禁用 | 不再执行，包括已排队未开始；已发远端请求显示真实取消边界 |
| AC25 | 归档已引用版本 | 新对话不可选，旧记录可读；旧调用仍需有效开关和准入 |
| AC26 | 从对话生成候选并取消保存 | 只有草稿，不新增可用能力；生成过程不执行候选代码 |
| AC27 | 用户审阅保存、验证、启用 | 三步独立；模型声称已验证不形成证据 |
| AC28 | 公共能力复制、公共版本更新 | 个人副本不被覆盖；不复制密钥、文件授权、启用状态 |
| AC29 | 失败、超时、网络断开与服务重启 | 不自动重跑或替代；unknown/interrupted 可追踪；旧结果保留 |
| AC30 | 幂等键同内容/异内容，双击保存或调用 | 同内容一个动作；异内容409，无重复远端调用 |
| AC31 | 原件/平台包导出后导入 | 原字节/文件哈希一致；不信任导出权限；凭据重新配置 |
| AC32 | 旧普通聊天、项目、文件、预置应用回归 | 原有链路不因模块新增而破坏；未迁移资产不被同名个人能力替换 |

## 测试分层

解析和 schema 用单元测试；用户隔离、事务、幂等和状态用临时 SQLite 集成测试；Python 使用真实 WASI；MCP 使用本地可控只读服务与故障替身；浏览器验收覆盖导入、待配置、试运行、启用、沉淀和换版本。真实外部服务只在明确选择测试样例后验收，不读取已有私人会话作为样例。

运行测试必须记录代码提交、包摘要、配置快照、执行器版本、样例和结果。文档中的示例本身不是测试通过证明。

## 实现前技术核对

先验证 WASI 对包文件挂载和标准库导入的实际支持；不能通过失败时使用宿主 Python 满足验收。核对当前模型支持的 schema 子集，超出范围的导入需有明确报告。实现 DPAPI 凭据存储及恢复测试，确保服务运行账户变化时明确提示重新配置。建立至少一个可信只读 MCP 服务及准入记录，验证协议版本、认证和结果边界。

这些是实现任务，不再改变已经确认的产品范围。若实验显示设计不可行，应更新技术说明并报告具体限制，不能静默缩小兼容性或放宽执行权限。
