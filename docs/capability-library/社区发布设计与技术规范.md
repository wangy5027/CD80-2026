# 用户能力社区发布

状态：2026-10-14 实施前设计；本轮需求依据见 [愿景落地](../vision-delivery/产品设计.md)。社区仅对本机平台登录账号开放，与维护者官方目录分开。

## 用户流程与范围

已验证的个人 Tool 或 Skill → 查看共享预览 → 确认发布不可变版本 → 他人查看并复制为个人资产 → 接收者测试及启用。Skill 的精确 Tool 依赖一起复制，最多16个包；不携带作者连接、凭据、输入文件、执行产物、测试输入输出或验证证据。发布前显示全部源包文件和权限，作者确认这些文件可共享；扫描不能证明任意文本不存在秘密。

同一来源的新发布另建版本，保留上一发布标识，不覆盖旧发布或个人副本。作者可撤回；撤回后其他账号不能读取详情或复制，既有个人副本仍归接收者。复制主能力始终创建独立资产；依赖可复用接收者已有的精确内容，但不改变它的启用/验证状态。

## 接口

前缀 `/desktop/api/community/capabilities`。所有请求用工作台 Cookie 鉴权，所有 POST 要求 `Idempotency-Key`；错误沿能力库 `error/code/requestId/details`。

| 请求 | 输入 | 结果 |
| --- | --- | --- |
| GET / | `kind,q,mine,limit,cursor` | `items,nextCursor`；已发布目录，mine 包括自己的已撤回条目 |
| POST /preview | `assetId,versionId,title?,description?` | `snapshotDigest,title,description,root,dependencies,sourceReview,warnings` |
| POST / | 上述输入加 `snapshotDigest,confirmSharing:true` | 201 发布详情 |
| GET /{releaseId} | 无 | 发布详情与 `isOwner,personalCopies`；不包含作者内部账号/资产ID |
| POST /{releaseId}/copy | `confirmDuplicate?` | 201 `assetId,versionId,dependencies`；同内容已有个人副本时要求明确重复复制 |
| POST /{releaseId}/withdraw | `revision` | 作者撤回后的详情 |

发布详情包括 `releaseId,releaseNumber,previousReleaseId,title,description,kind,status,revision,publishedAt,contentDigest,snapshotDigest,root,dependencies`。root 与 dependencies 提供 `name,kind,sourceIdentity,contentDigest,permissions,files,manifest`，不含个人调用结果。预览摘要绑定标题、说明、源包字节与完整依赖，正式发布再次核对有效验证和摘要。

发布预览中的 root 和每个 dependencies 节点额外提供 `sourceFiles: [{path,text,sha256,size}]`，包含本次快照实际打包的 `capability.json` 和所有声明的资源文件。`text` 是完整UTF-8内容，`size` 为解码前字节数；源码只来自该预览的精确源包字节，不通过资产最新版补读。前端按能力及文件显示全文供作者展开审阅，再确认发布。发布后的公共详情继续使用原摘要结构，不自动返回源码全文。

顶层 `sourceReview` 返回 `fileCount,totalBytes,maxFiles,maxBytes`；全部根包和依赖包合计最多512个文件、4 MiB源码字节（包含各包的 `capability.json`）。预览和正式发布都实施这个审阅上限，超限返回413 `SHARING_REVIEW_LIMIT_EXCEEDED` 及同结构限制/计数详情，要求拆分包后重新预览；不截断、不显示省略正文后要求确认。该上限约束新发布，不修改已有快照或个人副本。

## 实现与安全

`community.py` 使用既有 SQLite 的独立社区 owner 和记录 kind；官方 `PUBLIC` 不变。源包由版本清单及索引字节重建，不导出原始上传 ZIP 中未声明的内容。发布内容不可变，撤回只修改状态和revision。私有发布映射保存作者归属和来源资产，公共响应按白名单构造。

`sharing.py` 检查清单、说明、文件名及文本内容中的凭据、私钥、带认证信息URL、私人文件/运行工件引用与宿主绝对路径。命中时拒绝整个发布，不静默修改代码。只接受明确声明且可审阅的UTF-8源码/文档/示例文本资源；二进制资源先在外部移除后再发布。MCP仅共享接口声明，不带个人连接或认证配置，接收者需自行配置且重新通过维护者准入。

发布和复制均用库锁串行化；一次复制在单个数据库事务内安装全部新资产、版本和字节，任一步失败回滚。复制依赖按拓扑顺序安装，重新计算接收者配置和准入状态；不复制作者验证。重复请求使用既有幂等记录，同键异内容409，未知结果不自动重放。数据仍位于 `capability-library/capabilities.sqlite3`，无需结构迁移；回退代码不会删除新增记录。

2026-10-14 审计补充：源包按文件名排序并使用固定 ZIP 元数据，预览摘要只随可共享内容变化，不随用户阅读预览的时间变化。复制明确绑定本次安装或复用的精确依赖版本，不能因接收者保留了同内容的归档资产而绑定到归档副本。文本检查同时解析 JSON、YAML、TOML 配置值，检查 URL 查询及片段中的认证参数，以及 `project-file:` / `library-file:` 私人引用；占位符与参数声明仍允许。

## 验收

覆盖真实WASI验证后发布、跨账号复制与默认停用、精确依赖与缺依赖、私有配置隔离、秘密/URL/私有资源扫描、未验证/配置失效拒绝、预览摘要冲突、不可变旧发布、重复确认、撤回权限、事务失败回滚及幂等。真实外部模型或数据服务不在该模块测试中调用。
