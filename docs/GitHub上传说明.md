# final_v1 源码发布说明

目标仓库：`wangy5027/CD80-2026`，分支：`final_v1`。来源为当前桌面“最终版”工程。此分支是经过检查的源码快照，不是包含私人账号、金融数据库和运行历史的整机备份。

## 保留的内容

- 平台与三个应用的前后端源码、依赖清单/锁文件、启动与运行资源安装脚本。
- `frontend/dist/`：正常主站直接提供该目录，必须与当前源码一起交付。
- 产品 `skills/`、Schemas、标准导入示例、测试代码与确定性测试样例。
- 官方能力目录、其引用的发布 ZIP 和完整性/准入元数据。它们是运行依赖，不是私人运行历史；不能按 `history`、`evidence` 或 `.zip` 一概删除。
- 当前产品与接口规范；文档中的历史材料链接在公开快照中改为“本地记录未随源码发布”的文字提示。

## 排除的内容

- 实际 `.env`、Token、私钥、认证文件和机器专用配置；仅保留检查过的 `.env.example` 占位模板。
- `data/`、SQLite/DB 及日志/WAL：包括账号、会话、聊天、文件上传、研究、策略、个人资产、应用运行与验证记录。
- `.run/`、缓存、已安装虚拟环境、`node_modules/`、日志、截图与浏览器验收产物。
- 历史归档、验收记录、开发进度、旧发布/迁移审计记录及本地备份。

这些规则只控制源码上传，不删除本机历史。Mac mini 的演示数据、各功能历史示例与自然语言创建/修改/使用用例，应以独立的私下迁移交付准备，不能通过公开仓库传送真实配置或用户数据。

## 克隆后配置

按照根目录 README 和 `LOCAL-MAC.md` 安装依赖，用 `.env.example` 创建本机配置并填入自己的凭据。WASI 运行资源按安装脚本单独准备；本地金融 SQLite 数据和策略行情映射需要另外获得并按文档放置。只有源码不能直接恢复原机器的账号、历史、金融数据或完整演示状态。

## 发布检查

`.gitignore` 不是对已跟踪文件或旧 Git 历史的清理工具。此版本从独立发布目录创建干净快照，不导入本地历史与旧仓库提交，不覆盖其他远端分支。提交前检查实际 Git 索引、已知本地秘密值、高置信密钥格式和 ZIP 内部内容，提交后核对远端分支提交与完整文件树。

运行检查日志、文件清单、摘要和私有备份保存在本机排除目录中，不随源码发布。已被排除的历史报告中的测试数字不能当作克隆后重新运行的结果。

本地金融验证脚本及后续审阅脚本所用的临时账号密码，统一由 `CD80_ACCEPTANCE_PASSWORD` 环境变量提供；需在同一次验证/恢复/审阅中使用相同值。未设置会在执行任何验证前停止，不再把该登录凭据写死到源码。它不影响正常平台登录配置。
