# 首批执行协议与实现计划

2026-10-13：用户第二轮 Q1—Q12 全部确认并授权实施。本页取代早期“仅文档/新闻第二批”的任务边界，范围含首批新闻；旧入口保留，个人副本不自动启用。

新增 `python_connector` Tool 执行类型，仍使用 WASI，不开放 guest 网络。包入口 `run(payload)` 接收 `{input, responses}`；返回 `{request:{connection,operation,arguments}}` 请求一次受控读取，或 `{result:...}` 完成。宿主累计读取结果重新执行包，最多 6 次读取、总时限 120 秒。包不得返回文件；包业务逻辑不进入宿主 handler。

清单 execution 声明 path、callable=run、connections 数组，每项 identity 和 operations；每个 operation 的参数 Schema 由维护者在服务连接注册表限定，包只能收窄声明，不可自行注册目标。首批注册本机数据读取与新闻 GET，通过已有 HTTP 路由语义执行；内部请求携带不可由 HTTP 客户端制造的服务器身份上下文，重新核对账号。凭据留在既有服务层，不交给 guest。响应有大小限制、无重定向，失败停止；每轮再次准入，记录读取摘要。不支持任意 URL、SQL、写方法。

官方示例新增可选 assertions：JSON 路径数组与 eq/type/minItems/requiredKeys/eachType/date 操作；使用声明式解释器，无 eval。Tool 示例须提供 expected 或非空 assertions；两者同时存在时全部成立。正式验证新增 mode=assertions。公共发布必须使用实际返回结果重新执行同一组断言，绑定精确清单/内容/配置证据。纯 schema 或非空检查不足以发布新闻示例，须同时核对来源、记录字段及时间格式。

首批：4 个 Tool（日线、公告、两融、新闻）及相应 Skill、独立对话表格 Skill。包放在 capabilities/local-financial/，平台只通过通用发布目录加载已验收版本，未验收包不可公开。输出提供日期、单位、来源、缺口和分页。新闻按现有缓存行为返回，失败不换来源。

验收顺序：协议边界单测→真实 WASI 与隔离账户→本地数据 HTTP→官方真实模型示例及效果复核→发布与个人复制/验证/启用/对话。每项分别记录，不自动修改正式个人账号。单项未通过保留待发布。

## 官方能力免配置修订

用户确认官方提供的连接与数据源应由平台准备。保存官方Skill时自动复制精确依赖、用官方Tool样例执行验证并准备为依赖使用；用户只测试Skill效果并决定启用。主Skill不会自动通过效果验证。已有个人副本提供“准备官方依赖”修复，不要求用户重新导入或填写MCP。明确禁用/归档的已有工具不擅自恢复；个人自建连接保持原有管理。所有准备是显式请求触发的后台任务，不在GET时访问上游或修改个人库。平台源故障提示平台服务不可用，不要求用户填地址/密钥。
