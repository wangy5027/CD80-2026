## 验收矩阵

| 编号 | 检查 | 通过条件 |
| --- | --- | --- |
| LF-01 | 数据一致性 | 不同证券/日期/空结果与只读基准查询一致，日期和单位正确 |
| LF-02 | 日期语义 | 未指定日期展示最新可用日；指定日期不偷换；区间缺口明确 |
| LF-03 | 两融计算 | 正常/空值/文本数字正确；余额、金额和数量不混淆；不补零 |
| LF-04 | 公告 | 筛选分页准确，仅返回承诺的元数据与链接，不编造摘要 |
| LF-05 | 记录与聚合 | 无分页遗漏/重复；关联和汇总不因版本或重复记录膨胀 |
| LF-06 | 只读连接 | 不能访问未授权目标、数据库路径或写接口；错误不绕过准入 |
| LF-07 | 失败行为 | 超时、超范围、不支持、无数据可区分；失败停止依赖计算，不回退南财 |
| LF-08 | 包生命周期 | 公共复制、精确依赖、验证、启用、禁用及旧会话锁定符合现有规则 |
| LF-09 | 更新 | 普通数据更新不要求重启用；代码/契约/关键配置变化按规则失效 |
| LF-10 | 对话表格 | 保留来源、数据日期、单位、缺失项；不调用截图或宿主浏览器 |
| LF-11 | 可插拔与独立性 | 金融逻辑在包内；不导入内部业务模块；不依赖南财接口/key |
| LF-12 | 新闻（首批） | 真实接口可用，来源和 stale 正确；失败不伪造新鲜新闻 |
| LF-13 | 历史分析（后续） | 财报披露时点、版本及分析基准日正确，不提前使用信息 |

测试应验证计算、数据口径、边界与真实集成，不仅镜像实现。性能按最终限额和常用查询规模核验，不扫描全库作为默认交互路径。
