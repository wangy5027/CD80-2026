# 本地金融能力技术规范

状态：架构及执行协议已落实。日期：2026-10-13。清单、连接和动态示例的现行契约见 [执行协议](执行协议.md)。

## 目标架构

`公共 Skill → 精确依赖的公共 Tool 包 → 平台通用受控连接 → 本地数据服务 / 明确允许的新闻接口`

金融查询、转换、计算逻辑位于 Tool 包。Skill 保存方法与解释。宿主负责通用执行、参数/权限校验、连接授权、版本验证与调用记录，不包含逐项金融 handler。包不直接读取宿主数据库，不直接导入项目内部 Python 模块，不执行任意 SQL。

“不耦合”指不依赖现有业务代码内部实现，仍通过版本化的能力包及数据接口契约协作。不要求运行时完全没有平台或数据服务依赖。

## 平台通用支持要求

- 包显式声明所需连接及只读操作，宿主配置地址/凭据，不随包分发秘密。
- 宿主执行连接白名单与参数约束，包和模型不能任意指定其他目标或宿主路径；不能只靠 Skill 指令保证。
- 仅开放已核对的读取接口，包括数据服务读取性质的 `POST /query`；不得按 HTTP 方法一刀切开放全部 POST 或写接口。
- 实现通用取消、超时、结果大小、错误和调用记录机制；保留现有 owner、版本、依赖、启用和权限检查。
- 新执行路径的验证证据应关联包实现、契约及有效连接配置，不能继续以南财代码或凭据摘要代表本地金融包。
- 通用支持未就绪，包标记待平台接入；禁止以金融 builtin 临时替代并宣称完成。

## 包与数据契约

沿用现有 `cd80.capability/1` 包规范及精确依赖机制；新增执行需求需经上述通用扩展正式定义后才能生成可验证清单。Skill 保留标准 `SKILL.md`；包保留来源和适配溯源，原始南财材料不被当作已验证运行资产。导出不包含凭据、宿主路径或验证授权。

第一批输入至少覆盖证券标识、日期/区间及有界分页；公告增加关键词。默认20条（新闻5条），最多100条（新闻20条），offset上限1000；日期采用YYYY-MM-DD。由包及宿主Schema校验。

结果语义必须表达：实际记录、来源表与字段/计算说明、请求范围、实际覆盖、数据截止日期、单位、缺失项与分页是否完整。与能力库现有 `content/sources/artifacts` 封装协调；首批无需文件产物。输出为source/as_of/records/units/returned_range/pagination/coverage/warning；新闻为provider_source/cache并保留原记录。具体以发行清单和包实现为准。

数值转换先识别空值/文本 NULL，再解析；证券前导零保留。日期解析兼容源格式，但不能只以字符串截断掩盖非法值。按业务键与版本规则选择记录，不按导入行号推断最新业务版本。跨证券排名、关联和聚合均防止重复膨胀。

通过服务接口读数据，复用既有服务，不复制业务数据库。原字段和通用查询参数以 [数据服务契约](../../cd80-data-api/docs/CONTRACT.md) 为准；首批映射见 [数据映射与覆盖](数据映射与覆盖.md)。

## 版本与数据变化

能力版本、连接配置与数据内容更新分别跟踪。代码/契约/关键配置/结构变化触发重检；普通数据新增不自动使所有个人能力失效。每次调用保存可获得的数据日期/版本信息，不承诺不存在的完整快照标识。旧会话锁工具版本但数据可更新，此限制向用户明示。

## 新闻

首批通过 [现有新闻 HTTP 契约](../news/技术规范.md) 接入，不导入新闻内部模块。登录身份经宿主私有上下文重新鉴权，不复制个人 Cookie 到包。保留来源、发布时间、抓取时间及 stale/warning，未有真实 Windows 验收前不称可用。新闻属于显式外部来源例外。
