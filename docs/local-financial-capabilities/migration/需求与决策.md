# 迁移需求与已确认决策

状态：产品范围已确认，2026-10-13。下列 R 项为用户决策；接口文档中的具体字段、数值上限和拆包名称为本次工程设计，不伪称用户逐项确认。

## 目标

R01：迁移三组能力。第一组完善已有日线、公告、两融、当前新闻和表格；第二组开放已有本地表并适配证券搜索、历史收盘/估值、财务、龙虎榜明细、有限宏观、有限事件和分类搜索；第三组补齐有界读取、覆盖信息、结构化错误、任务预算与取消、受控中间结果，以及供后续完整排名使用的通用排序聚合支持。

R02：金融逻辑留在可版本化、可解释、可复用的 Tool 包中；Skill 描述方法、调用、适用范围和结果说明。使用现有能力库导入、验证、启用、版本和精确依赖机制。不能通过增加逐金融功能的宿主 handler 替代迁移。

R03：现有数据不足的功能不伪装为迁移成功。结构化数据只用本地库；新闻继续采用已确认的 AkShare 来源例外。失败不自动改用南财或其他外部来源。

## 已逐项确认的能力行为

| 决策 | 内容 |
| --- | --- |
| R04 历史行情范围 | 股票、ETF、指数的不复权日/周/月线；复权另议 |
| R05 历史行情取数 | 可扩展有界读取，保留超时、取消和总量限制；取不齐不能称完整 |
| R06 周月计算 | 自然周周一至周日、自然月；先补齐周期起点取数再聚合，显式日期区间按周期结束日期筛选 |
| R07 缺数 | 不自动补价格或成交量；区分周期未结束与记录完整性未核实 |
| R08 默认历史范围 | 最近20个有记录的周期，包含最后一个未结束周期并标明；证券实际日期与数据集截止日期分别显示 |
| R09 历史旧版退出 | 删除 sfc-history、sfc_history 注册及专属实现；共享南财客户端暂留；旧应用/待执行方案提示迁移重新确认，保留历史记录，不静默替换 |
| R10 公告范围 | 仅标题、日期、证券、原文链接，不下载正文，不做全文分析 |
| R11 公告证券条件 | 证券代码必填，关键词只过滤该证券标题；跨证券检索由 sub-agent 配合明确的搜索能力解决，不在公告 Tool 放宽 |
| R12 公告默认日期 | 数据集截止日前30个自然日，每页20条；显式日期严格使用；显示截止日期，不称今日 |
| R13 公告旧版退出 | 删除 sfc-announcement、sfc_announcements 及专属列表/详情实现；旧详情不静默降级成标题；历史记录保留 |
| R14 两融范围 | 本次必填证券代码、单证券核心字段查询，不交付全市场两融榜单 |
| R15 批量决策方式 | 不继续逐技能逐字段访谈，由文档统一明确迁移方案与符合 sub-agent 的通用扩展 |

R11不等于“模型凭关键词猜股票代码”。本批证券/分类搜索只保证名称或代码匹配；任意公告事件关键词到证券的检索没有已确认数据工具支撑时，sub-agent 必须澄清或报告能力不足。不得暗中增加跨证券公告搜索来绕过 R11。

## 不在本次范围

研报数据建设、完整概念主题、实时行情、公告正文/OCR、持久化历史新闻、完整经济金融事件日历、复权、模拟交易、自选账户写入、原版任意宿主脚本与浏览器截图。行业分类查询是受限本地对象查询，不冒充主题推荐。

通用排序/聚合属于第三组基础设施；全市场两融业务榜单仍由 R14 排除。图表和临时代码的授权、渲染能力归 sub-agent 既有项目，本轮仅提供可靠输入与文件结果衔接，不复制建设。

## 默认工程选择及调整规则

采用本目录接口中的保守默认值和命名；先验证其与正在开发的 sub-agent 相容。若源码已有同义契约，复用并更新映射，不制造第二套 ID、预算或工件系统。数值限制经边界测试可调整，但必须有明确上限、部署配置、兼容说明和验收记录。发现数据不能支撑承诺时缩小“可用状态”并报告缺口，不静默缩小已确认功能后宣布完成。

R09/R13是明确删除授权。其他南财能力不作全量删除：对应本地替代验收后默认展示本地能力、清楚区分来源；删除会损失未迁移子功能时列入退出清单，不能自行永久移除。此轮仅写文档，未执行任何删除。
