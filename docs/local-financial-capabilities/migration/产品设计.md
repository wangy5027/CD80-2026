# 本地金融能力迁移产品设计

状态：待实施目标，2026-10-13。产品约束见[需求与决策](需求与决策.md)，能力边界见[迁移清单](能力迁移清单.md)。

## 用户与交付

面向通过主对话或 sub-agent 查找、比较和整理本地金融数据的用户，也支持在扩展详情中独立测试 Tool。用户无需填写官方本地数据库地址或南财凭据。公共包保存到个人库后，由已有官方准备流程处理精确依赖；主 Skill 仍需效果验证并主动启用，不以发布证据替代个人验证。

每项能力详情展示：适用问题、支持资产与数据字段、不支持范围、数据截止/覆盖限制、可填写的官方示例、预期结果或人工评审标准。失效、缺依赖、待验证和禁用分别展示，不以灰色按钮代替原因说明。

## 标准使用流程

1. 名称不明确时通过证券搜索取得带市场与类型的候选；重名、多个市场或匹配不足时澄清，不按第一个候选猜选。
2. 调用具体金融 Tool，绑定准确版本、用户、输入及本任务数据授权。是否使用 sub-agent 由已有任务系统决定，简单查询不强制委派。
3. 确定性查询与转换由 Tool 完成，模型不得补造数值。后续计算使用实际完整数据或授权结果引用，不能把有界预览作为全量输入。
4. 用户看到来源、实际日期、单位、返回范围、分页/预算截断和缺失说明；不同数据日期不伪装成同一时点。
5. 子任务由主 agent 验收后交付；平台实际调用证据与数值校验先于模型“成功”陈述。权限或数据不足则保留部分结果并解释边界。

## 三个已确认流程

### 历史行情

默认日线、最近20个有记录周期，日/周/月参数可选。显式区间按周期结束日期纳入；周末/月末未到的周期，默认最近查询可包含，显式区间仍按其自然结束日期筛选，不混用两套语义。排序默认最新在前，计算前先按日期升序。

周/月 open取首条、high取最大、low取最小、close取末条；vol与amount只有该周期所有已取记录相应字段均有效时求和，否则该字段为null并提示缺失。此规则不证明缺失交易日不存在。涨跌幅依据可靠前周期收盘计算，不能累加日涨跌幅；没有前值则null。补取前周期只是计算输入，不擅自扩大用户展示区间。计算与边界测试见验收用例。

最后一周期在数据截止时尚未结束则标记开放中；时间已结束但数据中途截止或交易日不可核验则保留完整性未知/不足标记。停牌证券无记录不补一根虚构K线。数据不足20条时返回实际条数，不找其他来源凑数。

### 公告

必填明确证券代码。默认区间为数据集最新日期D的[D-29日,D]，含首尾；无最新日期则返回空库信息，不采用机器当天兜底。关键词仅匹配标题。默认20条，支持继续翻页；默认日期倒序，同日按稳定行标识排序。无正文仅显示原始标题与链接，链接存在不代表已经读过内容。

### 两融

必填6位证券代码；同码涉及不同市场且无法唯一确定时必须补充市场或澄清，不能合并。保留现有默认数据集最新日期查询；明确输出证券是否在该日有记录，空结果不自动换日。支持指定日期/区间。买入或偿还任一缺失时净买入null；融资余额和两融总余额分列。金额单位未核验前标为源表原值，不换算；不做跨证券榜单。

## 搜索与组合边界

证券搜索解决名称/代码到证券标识；分类搜索增加基金、ETF、有限行业对象。它们不等于公告全文、新闻历史或语义选股。用户说“回购公司”但没有相应检索工具时，sub-agent 不得依赖模型记忆生成候选。

财务比较、龙虎榜汇总等组合必须验证相同口径和实际覆盖；输入有截断时只允许明确标记的部分分析。聚合排名只有完整候选集或受控服务全范围计算的证据才能称全范围，不能从有限页推断。

## 错误体验

输入无效：标注字段与允许范围；无匹配：返回空记录及真实查询范围；能力不支持：说明具体子功能；数据不足：返回已取结果与未完成原因；服务失败：保留错误，不包装成空列表。取消后停止新调用并丢弃迟到成功；重新执行必须遵循任务系统规则，刷新只观察。

旧南财历史/公告引用显示“旧能力已移除，请选择本地版本并重新确认”；历史记录仍可读。主站不能以改名方式暗中让旧审批绑定新的数据源和算法。

## 交付条件

每个能力包含独立 Tool/Skill 包、说明、参数表单、官方样例与证据；明确实现状态、自动测试、真实本地接口、真实模型效果四种事实。不能以基础设施完成代替各能力完成，也不能因财报/宏观数据不足宣称覆盖南财全部功能。
