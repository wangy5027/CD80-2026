# 本地金融公共能力产品设计

状态：已确认需求。日期：2026-10-13。依据：本次 grilling 需求对接 Q1—Q15 及最终确认稿，用户先授权写入文档，第二轮确认后授权实施。现行执行细化见 [执行协议](执行协议.md)。

## 目标与交付对象

将适合本地数据的南财功能改造成平台可插拔的公共 Skill 包和 Tool 包。Skill 描述研究方法、调用顺序、结果解释及缺数处理；Tool 包保存查询、字段转换和计算逻辑。金融逻辑不作为平台业务代码的一部分，不采用逐项硬编码 handler 接入。

能力通过明确接口访问数据，不直接导入现有工作台、南财工具或新闻模块的内部代码。第一版只服务新能力池，不额外维护旧内置技能入口。以本平台能力包规范下的导入、导出和独立版本管理为目标，不承诺跨 AI 平台无需适配即可运行。

## 数据来源

结构化行情、财务、估值、公告元数据、两融、龙虎榜等只读取本地金融数据库，经既有数据服务接口访问。不调用南财接口，不使用南财 key，不自动切换其他来源。

新闻是已确认的独立例外：首批允许经本地新闻接口获取 AkShare 新闻，明确标注东方财富、财联社等实际来源、发布时间和缓存状态。这是联网数据，不是本地持久化新闻库。Windows 真实上游已于本轮验证，仍按每次调用结果判断可用性，不得将其作为其他查询失败时的自动替代来源。

## 首批功能

| 能力 | 承诺范围 | 不包含 |
| --- | --- | --- |
| 历史行情 | 股票、ETF、指数不复权日线，日期筛选、排序、分页 | 实时、分钟线、复权 |
| 公告检索 | 按证券、关键词、日期查询标题与原文链接 | 正文抓取、摘要、内容分类 |
| 融资融券 | 融资买入、偿还、余额、净买入等已明确口径的查询 | 未确认口径的比例与衍生指标 |
| 已接入新闻 | 东方财富/财联社当前接口、来源时间与缓存标记 | 全量历史新闻、自动换源 |
| 表格展示 | 对话内展示数据、单位、日期、来源和缺失说明 | PNG 截图、文件导出 |

业务能力不要求机械地一对一对应 Skill 和 Tool。包数量、命名及精确接口在实现前技术细化；不能将本页范围误认为已存在的工具名称。

## 结果与错误体验

1. 未指定日期时返回该数据集最新可用日期，并明确显示；指定日期时严格查询，不擅自改成其他日期。
2. 区间覆盖不足可返回已有部分，同时说明实际范围；总体最早/最晚日期不代表每只证券连续完整。
3. 无法满足实时或今日请求时明确说明，不能将历史收盘数据包装为现价。
4. 跨表分析明确基准日，分别保留行情日期、财务报告期和公告日；历史分析不得使用当时尚未披露的信息。
5. 区分零、空值和无数据，不自动补零；统一日期、证券代码和单位，按业务语义处理重复与版本。
6. 结果可追溯至数据表、字段、日期和计算口径。查询失败后停止依赖结果的计算，不自动换来源补齐。
7. 超范围、不支持、覆盖不足和接口失败分别说明；不将失败或截断结果标为完整成功。

## 公共分发与个人使用

平台提供公共 Tool 与 Skill 包。用户先将 Tool 加入个人库、验证并启用，再加入依赖它的 Skill、验证并启用。个人副本独立保存，公共更新不自动覆盖；依赖按明确来源身份和内容摘要解析，缺失时告知具体缺项。

沿用现有保存、检查、验证、启用的独立流程。不增加一键领取整套能力、自动安装依赖、自动推荐或替代工具。禁用与运行时权限检查仍对旧对话生效。

## 更新与非目标

代码、契约、关键配置或数据结构变化需重检，按影响范围使验证失效；普通数据更新不要求用户反复启用，输出记录实际数据日期和可用版本信息。历史对话锁定能力版本，不冻结数据库内容。本期不建设完整历史数据快照和完全复现系统。

本次迁移不修改或清洗覆盖原始表，不补齐历史数据，不建设自动更新，不承担全部数据治理。资产负债表、复权因子和交易日历缺口独立记录，功能受限时明示。

第二批考虑财务指标/利润/现金流/估值、龙虎榜、有限宏观、本地搜索、收盘排名、周月线/技术指标、AkShare 新闻；之后才做图表、文件和综合分析。新闻历史库、研报、概念主题库、实时行情、自选股管理和模拟交易不在本轮承诺内。
