# 数据映射与覆盖

日期：2026-10-13。依据：本次对 `cd80-data-api/data/cd80.sqlite3` 的只读结构、范围及样本查询。37 张业务表；元数据登记总计 19,274,362 行。以下为检查时快照，不代表持续更新承诺，范围端点不证明逐证券完整性。

## 首批候选映射

| 能力 | 表/字段 | 转换与约束 |
| --- | --- | --- |
| 股票日线 | `cd80_daily`：ts_code/trade_date/open/high/low/close/pre_close/pct_chg/vol/amount | 元数据标注 vol 为手、amount 为千元；输出明确单位，按目标口径换算 |
| ETF 日线 | `cd80_etf_fund_daily`：ts_code/trade_date/OHLC/vol/amount | 单位独立核对，不能仅凭同名字段照搬股票单位 |
| 指数日线 | `cd80_index_dd`：ts_code/trade_date/OHLC/vol/amount | 日期存在带 .0 的文本；单位和代码独立验证 |
| 公告列表 | `cd80_anns_d`：ticker/security_name/announcement_date/announcement_title/url | 仅标题与链接，无正文、摘要或完整类型分类；不自动抓取链接 |
| 两融 | `cd80_margin_data`：SYMBOL/EXCHANGE/TRADEDATE/FINBUYAMT/FINREPAYAMT/FINBALANCE/FINMRGHBAL | FINREPAYAMT 等为文本；融资余额与两融余额分开；净买入为有效买入额减偿还额 |
| 证券名称 | `cd80_stock_basic`：ts_code/symbol/name | 关联时处理交易所和缺名称，不凭证券前缀覆盖正式代码映射 |

两融的 `MRGNSELLAMT` 字段说明为融券卖出数量，不能误作金额。交易所内部编码需明确映射后使用。表格展示消费查询结果，不引入新取数来源。

## 已观察的数据覆盖

| 数据 | 检查结果 | 限制 |
| --- | --- | --- |
| 股票日线 | 2024-07-01—2026-09-30；最后一天 5,561 个代码 | 非实时 |
| ETF/指数日线 | 最新到 2026-09-18 | 不与股票同步 |
| 两融/龙虎榜 | 2025-07-02—2026-09-29 | 历史窗口有限 |
| 公告 | 1,852,567 行；2024-07-01—2026-10-01 | 元数据与链接，不是正文库 |
| 复权因子 | 最新到 2026-09-24 | 首批不开放复权 |
| 资产负债表 | 8 行，5 个证券代码，报告期均为 2026-06-30 | 不支持全市场完整基本面 |
| 财务指标 | 8,643 行，3,860 个不同证券代码 | 不保证连续多年或全市场 |
| 交易日历 | 只到 2025-12-31 | 不能判断 2026 年交易日 |
| CPI/LPR | 分别 2,637/102,295 行，512 个不同月份/1,532 个不同日期 | 同期多记录需核实语义 |

已见日期有 YYYYMMDD、YYYY-MM-DD、YYYYMMDD.0；部分数值为文本，缺失值同时存在 SQL NULL 与字符串 NULL。ETF 基础表 5,502 行但仅 1,195 个不同代码，不能直接关联造成结果膨胀。龙虎榜同证券同日多营业部明细属于正常结构，不能据此粗暴去重。

`cd80_factor_list` 约 121 万行、282 个不同因子名称，内容为名称/分类/描述，不是按股票日期存储的因子值库。

## 接入前必须核实

- 各资产单位、交易所编码、业务键和重复记录选择规则。
- 数据服务是否能满足所需筛选与分页；不能因接口不足转为开放任意 SQL。
- 逐证券覆盖、字段有效率及指定日期无数据行为。
- 财报公告日期、报告版本、合并口径和累计/单季口径；后续财务技能启用前完成。

数据字典权威入口为 [数据目录](../../cd80-data-api/docs/data_catalog.json)。此文件仅记录迁移映射和风险，不替代原字段目录，不修改原表，不承担补数或采集任务。
