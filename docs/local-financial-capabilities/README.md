# 本地金融公共 Skills / Tools

## 依赖与源码现状

- [能力库](../capability-library/README.md)：公共/个人副本、包版本、依赖、验证与启用。
- [金融数据服务契约](../../cd80-data-api/docs/CONTRACT.md)：本地结构化数据的现有接口；不复制或改写其权威字段定义。
- [新闻接口](../news/技术规范.md)：本地服务通过 AkShare 联网抓取，只有进程缓存，不是本地新闻数据库。
- [架构决策](../decisions/0002-本地金融可插拔能力.md)：不采用金融 builtin 硬编码接入。

能力包源码在 `capabilities/local-financial/src/`，独立发行包在 `capabilities/local-financial/packages/`，构建入口为 `scripts/build_local_financial_packages.py`。现有代码依据位于 `backend/app/modules/capability_library/`、`backend/app/modules/news/` 和 `cd80-data-api/`。这些是依赖系统，不是允许金融包直接导入的内部模块。

第一批为不复权日线、公告列表、融资融券核心查询、已接入新闻及对话内表格。通用受控连接执行支持是启用前置条件，当前不能承诺原南财脚本导入即可运行。

精确执行协议、连接与动态示例规则见 [执行协议](执行协议.md)。
