# AkShare 财经新闻技术规范

状态：2026-10-13 代码现状整理；接口或数据变化时同步维护。

routes.py 负责 Cookie 与参数，service.py 按来源缓存，provider.py 规范化字段，worker.py 子进程配合硬超时。缓存属于单个主站进程，不持久化；过期由请求触发，不是定时任务。

GET /desktop/api/news/sources 返回 provider、default_source、sources 和 refresh；GET /desktop/api/news 接受 source=eastmoney|cls（默认 eastmoney）、limit=1..100（默认20）、offset=0..1000（默认0）、q（最多80字符，无控制字符）。未知或重复参数400，未登录401。接口只读，写方法拒绝。

结果含 provider/source/source_name、items、pagination、cache、latest_published_at、warning。items 包含 id、title、summary、published_at、url、title_generated；url 可能为空。pagination 的 total 是当前来源缓存筛选后的数量，不是上游历史总数。

cache 含 hit、stale、fetched_at、expires_at、age_seconds、ttl_seconds、refresh_retry_after_seconds。正常 warning 为 null；失败使用旧缓存时返回 code/message 并标记 stale。默认 TTL 60 秒、抓取15秒、旧缓存最大900秒、退避30秒，由 NEWS_* 配置覆盖。

无可用缓存时，上游异常502、依赖/进程不可用503、超时504；错误为主站 error/code 格式。旧 API 完整示例原文保存在 历史副本（本地资料，未随源码发布），当前参数以本页和代码为准。
