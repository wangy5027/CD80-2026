# 基础工作台产品设计

状态：2026-10-13 对现有功能的现状整理，不是补写的历史审批。新需求需明确确认后更新。

用户注册或登录后发起普通对话，管理历史任务、文件和项目；日程用于浏览器到期提醒。默认主助手分流和应用流程由应用平台负责，用户也可选择普通对话。

主要流程：登录 → 新建/恢复任务 → 输入文字及支持的文本附件 → 流式回复或停止 → 重新打开历史。项目用于组织任务和文件，删除项目只解除归属。文件显示应能区分同名不同内容，页面草稿应按账号隔离。

验收条件：
- 未登录不能读取他人业务资源，账号切换不出现迟到的旧账号响应。
- SSE 支持分块 UTF-8，停止后保留可用的部分回复；真实停止时延需测量。
- 文件上传、下载、删除与项目归属一致；错误可理解。
- 页面切换和刷新时草稿行为符合当前设计，失败提交不丢内容。
- 日程明确是浏览器提醒，不暗示后台自动执行。


## 2026-10-15 首页创建模式

首页和已有对话输入框新增默认关闭的“创建模式”。选中后，每次发送都显式进入技能池的自然语言 APP 创作流程；需求全文与所选文件引用传入同一接口。必要补充在同一次创作内回答，完整应用保存后定位“技能池 → 我的 APP”，初始为未验证、未启用并保留原任务用例。关闭后恢复普通问答。异常恢复、账号切换及验收边界见[创建模式规范](首页创建模式.md)。
