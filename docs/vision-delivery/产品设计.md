## 资产含义

- Tool：有明确输入与输出的独立计算或受控连接操作。
- Skill：可复用的方法说明与精确能力依赖，必须效果验证。
- 应用：用户可反复运行的目标、输入与方法。已有固定流程应用保留；新增研究应用保存参数化任务与约束，交由既有主/子agent重新规划执行。
- 子任务：一次执行记录，不是自动公开的应用。保存动作独立，成功记录只作来源，不把旧结果当作新运行输出。

两个应用执行方式清楚标示：固定流程按已审阅步骤运行；研究应用由agent按本次输入重新执行。均不承诺保存一次即可证明所有输入正确。

## 交互

1. 首页保留Explore/Build/Evolve，提供具体入口和可填写示例。
2. 成功子任务卡提供“保存为应用 / 保存方法 / 保存计算工具”，打开可编辑预览；失败任务不能冒充已验证资产。
3. 研究应用编辑目标模板（如“分析{{证券}}在{{区间}}的价格变化”）、名称、约束与能力。每次运行填写参数并重新授权文件。
4. 应用页提供个人、预置/共享来源、导入、导出、改编与运行；组件详情保留测试/启用，并增加发布。
5. 发布先预览将共享的说明、源码、依赖与权限，再明确确认。发布范围是本机平台所有登录账号；不等于互联网部署或比赛提交。
6. 接收者复制为独立资产。Tool/Skill重新配置、验证、启用；应用重新确认运行，不继承作者输入或权限。发布更新不覆盖副本，撤回只阻止新获取。

## 验收与边界

- 外部样例导入→预览保存→授权执行→结果→导出→另一账号导入复用。
- 成功任务→保存研究应用→不同参数新运行；原轨迹/数据不被硬编码为新结果。
- 成功代码→可编辑Tool草稿→保存→实际测试→启用→调用；方法同理。
- 已验证个人能力→预览发布→另一账号复制依赖→验证启用→调用；撤回后不能继续复制。
- 个人能力组合进入固定应用，禁用、版本/配置变化时执行仍受准入约束。
- 跨账号越权、重复请求、秘密泄露、缺依赖、取消、失败及窄屏均覆盖。
