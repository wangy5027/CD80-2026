# 愿景落地技术规范

## 2026-10-14 后续目标契约

Creator 沉淀、统一 App 入口、旧 recipe 与 pipeline 可追溯升级、资产包与运行材料分离按[可复用资产目标技术规范](../asset-authoring/技术规范.md)实施。产品已定稿，新增代码、机器契约和迁移尚未实施；本文下述实现说明仍对应当前版本。目标逻辑对象与操作语义不表示已有同名 HTTP 接口或物理表。

状态：2026-10-14 实施方案及本轮增量修订。研究应用字段与状态见[接口契约](研究应用与发布接口.md)，应用包和组件社区细节由对应模块维护。

## 兼容与模块所有权

- agent_platform保持既有 `schemaVersion="1"` 固定流程与agents接口；增可移植包、改编及个人能力引用。个人引用绑定用户、精确内容与配置，执行前重新admit。
- capability_library新增community模块与独立路由，社区资源与PUBLIC官方资源分离。复用原包解析、内容摘要、数据库事务、导出检查与个人导入。
- evolution新增研究应用与子任务沉淀接口；复用sub_agent调度、WASI和能力库草稿。研究应用仅存定义与来源，执行需新消息/新参数/新文件授权，不重播旧结果。
- 前端新增复用与共创入口，保留旧应用/能力详情和流程；任务卡沉淀操作均由用户明确触发。

## 可移植应用

外层约定 `format="infinity-application"`、`formatVersion="1"`、kind为pipeline或recipe、definition、dependencies、provenance。格式版本、固定流程schemaVersion和各version字段均使用字符串 `"1"`。包中不包含Cookie、API key、个人连接配置、运行记录、授权文件和产物。各kind独立校验、展示执行方式，不把动态轨迹转换为伪造固定流程。

固定流程至少实际执行一个tool，且只有一个位于末尾的model解释步骤，故有效pipeline为2—8步。个人Skill需要的精确Tool由requiredTools与依赖引用共同约束；入口同级的UTF-8参考资源提供给固定流程解释，含脚本的Skill明确拒绝进入固定流程，需使用可重新规划的研究应用路径。详见[应用包与组件复用](../agent-platform/应用包与组件复用.md)。

依赖可移植身份为sourceIdentity及内容摘要，个人assetId/versionId仅存本地绑定。导入不执行，依赖不足显示具体缺口，不能因同名自动匹配；确认保存和执行分别处理。

研究应用导入与社区复制接受dependencyBindings，新包按独立bindingId映射到{assetId,versionId}；每个槽位保留自己的精确选择，不按sourceIdentity把不同副本折叠。旧包仅在sourceIdentity唯一时兼容旧键，旧重复来源包需重新导出。固定流程使用tool:componentId或skill:componentId，兼容不歧义旧裸id。没有绑定时仅单一精确匹配可自动选择；多个副本返回DEPENDENCY_AMBIGUOUS及账号内候选，必须明确选择，不能根据启用状态猜测配置。候选包含旧版本。绑定仍需核对来源、内容与类型；执行时另行准入，不能借导入获得验证状态。

## 社区发布

/desktop/api/community/capabilities：列表、发布预览、确认发布、详情、复制、撤回。发布要求内容/配置对应的有效验证，预览摘要绑定待公开字节。共享只包含清单、源码和精确依赖包，最多16项。秘密与私密路径检查覆盖说明和源码；发布不是授予执行信任。

预览的 `root.sourceFiles` 与每个 `dependencies[*].sourceFiles` 返回 `{path,text,sha256,size}`，全文来自本次锁定版本的实际打包字节，包含各包的 `capability.json` 和全部资源，不根据最新版补读。全部主包和依赖合计最多512个文件、4 MiB源码字节；预览及正式发布均实施上限，超限返回413 `SHARING_REVIEW_LIMIT_EXCEEDED`，不得截断后要求确认。顶层 `sourceReview` 返回数量与上限。前端按组件和文件展开全文，源文件不完整时禁用发布确认。权威字段、错误及兼容边界见[社区发布设计与技术规范](../capability-library/社区发布设计与技术规范.md)。

社区列表使用 `items,nextCursor`；前端跟随全部游标后执行名称/用途搜索、类型及个人发布筛选，不能只过滤第一页。过期请求停止后续翻页，重复游标明确报错，不显示旧账号结果。

复制时依赖先行导入，副本默认停用、未验证。不复制作者配置、验证证据或私人数据；撤回后既有个人副本保留。账号身份从Cookie取得，客户端owner字段不可信。写接口采用Idempotency-Key，同键异内容冲突。

## 研究应用与沉淀

研究应用存参数模板、参数列表、约束、精确能力依赖和可选来源；模板仅替换显式占位符，不执行表达式。运行时校验参数、所有权、能力准入及文件授权，然后提交既有消息协调器。保存与运行分离，旧输入和产物不自动继承。

同一研究应用不能将一个个人能力同时锁定到不同版本，也不能将同一可移植来源身份绑定为不同内容或类型；重复的相同引用可去重，冲突需明确报错，不能按数组顺序静默覆盖。名称缺失等不完整定义按400处理，不创建记录。

Skill沉淀提供方法草稿，用户审阅后保存及效果验证。Tool沉淀仅取成功代码步骤的实际源码，输入工件变为具名参数/新文件授权，不打包工件原始数据；不把一次成功直接授予新工具verified状态。不支持的来源明确报错。

实际调用与精确依赖取证、间接 Tool 依赖、单步骤选择及私密路径检查的增量约束见[沉淀依赖与步骤范围](沉淀依赖与步骤范围.md)。仅加载、失败调用及默认最后一步均不能被表述为完整算法已自动沉淀。

## 外部开发资料包（2026-10-14补充）

`GET /desktop/api/evolution/developer-kit`沿用登录鉴权，返回项目内明确白名单资源。除两类应用样例与合成CSV外，包含可直接导入的十进制Tool和摘要Skill ZIP、对应展开源码、能力Schema、能力包/接口说明及本地金融协议。下载不读取个人资产、连接或运行数据，不执行样例。外部作者修改源码后须重新生成文件摘要，资料包提供仅使用标准库的打包脚本；脚本不执行包内源码。验收须对下载出的实际Tool包导入、验证、启用并换输入执行，不能仅检查ZIP文件存在。

资料包可脱离仓库使用；已收录资源的相对链接按ZIP内位置重定位，未收录历史记录明确标注完整项目参考，不能伪装为包内链接。下载内容的链接和样例摘要由test_developer_kit校验。外部指南串联需求与文件交给外部LLM、生成JSON、导入检查、两份输入验收、修改逻辑再验证及分享流程。

## 存储、权限和验证

新增研究应用/来源信息采用独立SQLite存储或既有逻辑记录表；不得破坏旧记录。发布字节不可变；新副本拥有独立ID。后端所有读取/修改再次检查用户，不靠前端隐藏按钮。

测试用临时DATA_DIR、模型替身和合成数据，真实WASI单独记录。前端修改后构建dist；浏览器以临时服务验证。真实模型检查另行记录时间、场景与限制，不用替身冒充。生产重启先查活动任务，不自动重跑用户失败请求。

本轮测试及正式服务状态见[验收清单](验收清单.md)和增量验收（本地资料，未随源码发布），各集合不能简单相加。原始SWUFE愿景已读取全文并[逐项核对](原始愿景逐项核对.md)。真实模型研究、边界场景、固定应用与隔离回归分别记录，不据此声称全部提示可靠或交易日覆盖完整。
