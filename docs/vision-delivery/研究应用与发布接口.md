# 研究应用、沉淀和应用发布接口

2026-10-14，依据当前evolution实现。前缀`/desktop/api/evolution`，登录Cookie鉴权。写接口除只读预览外需要`Idempotency-Key`头（1–150字符）；同账号、动作、标识和内容重试返回已有结果，不同内容409。成功JSON无统一外层包装；错误含error/code/details。请求受2 MiB上限。

## 研究应用

| 方法与路径 | 输入 | 返回/行为 |
| --- | --- | --- |
| GET `/recipes` | 无 | `{items:[研究应用]}`，只列本人 |
| POST `/recipes` | name、goalTemplate；可选description、constraints、capabilityRefs、sourceRunId | 201，保存定义，不执行 |
| GET `/recipes/{id}` | 无 | 本人研究应用；不可见404 |
| POST `/recipes/{id}/fork` | 可覆盖name、description、goalTemplate、constraints、capabilityRefs | 201，新独立ID，保留来源 |
| POST `/recipes/{id}/run` | input；可选fileIds、taskId、searchMode | 202，子任务对象；用子任务接口观察 |
| GET `/recipes/{id}/export` | 无 | 可移植JSON附件，无个人能力ID和历史授权 |
| POST `/recipes/import` | package；可选dependencyBindings | 201，静态保存，不执行 |

名称1–128字符，目标1–16000字符，说明最多4000字符。`{{参数名}}`仅纯文本替换，最多20个变量；允许中英文、数字、空格、下划线、短横线，不求值表达式。constraints最多20项，每项最多2000字符；capabilityRefs最多8项，每项`{assetId,versionId}`。sourceRunId必须是本人成功子任务；未提供则可独立创建。改编保存新记录，不覆盖原定义。

运行input须恰好包含全部变量，每项非空文本、最多4000字符。每次只使用本次fileIds，不继承旧文件；无taskId时创建新会话。能力须仍属本人、配置/验证有效且已启用。服务器设置内部executionContext.kind=recipe，避免再次分流为创建应用；客户端不能自报此上下文。

导入外层`format=infinity-application, formatVersion="1", kind=recipe`；definition只含name/description/goalTemplate/constraints。新导出dependencies每项`{bindingId,sourceIdentity,contentDigest,kind}`，要求精确来源、64位摘要和tool/skill类型。bindingId是独立选择槽位，默认按顺序为`capability-1`至`capability-8`，允许以英文字母开头的1–64位字母、数字、短横线和下划线。应用内部以capabilityBindingIds保存有序槽位；导入后再导出、未改变能力选择的改编保留原槽位ID，不携带个人能力ID或配置。

新包绑定为`dependencyBindings[bindingId]={assetId,versionId}`；相同来源与内容的两个个人组件仍是独立槽位，须分别绑定不同assetId。不得把两个槽位静默合并；选择同一资产返回409 DEPENDENCY_BINDING_CONFLICT。没有绑定时仅唯一精确匹配可自动选择；缺失409 DEPENDENCY_MISSING，多匹配409 DEPENDENCY_AMBIGUOUS且details.dependency保留bindingId并返回账号内candidates。旧版本可绑定，不自动变更activeVersion。冲突来源的不同内容或一个资产多版本不能静默覆盖。

兼容旧版dependencies无bindingId的包：各sourceIdentity唯一时仍使用`dependencyBindings[sourceIdentity]`，导入后分配有序槽位。旧包重复来源无法恢复原本的独立选择，明确拒绝并要求重新导出；新旧槽位格式混用、重复bindingId、未使用的绑定均拒绝。研究应用运行仍只传递assetId/versionId，按本次有效配置准入；独立副本的Skill工具依赖锁和执行来源分别保留。

## 成果沉淀

`POST /captures/preview {runId,kind,stepId?}`，kind为recipe/skill/tool；只读预览不要求幂等键。recipe返回`{kind,recipe,warnings}`，包括目标模板、约束、精确能力及来源。skill/tool返回`{kind,draft,warnings}`，由用户审阅后另行保存。Skill整理成功步骤目的、约束及精确Tool依赖，不等同自动复制原Skill全文和资源；Tool读取本人成功步骤的源码，将工件ID改为新文件参数，不携带原始字节。

Tool额外返回`selectedStepId`和`steps:[{stepId,label,purpose,inputCount,inputs}]`；inputs为`{parameter,label,sourceType,sourceLabel}`，来源类型区分tool/code/upload/previous_run/unknown。默认最后一个成功代码步骤，也可携带stepId选择另一成功步骤；仅沉淀所选一步，前置取数、其他计算和中间产物须另行准备。仅加载或失败调用不作为Skill依赖证据；同源不同配置、缺少精确锁、来源脚本或历史绘图环境无法保留时明确SOURCE_NEEDS_EDIT。详情见[依赖与步骤范围](沉淀依赖与步骤范围.md)。

非成功来源409 SOURCE_NOT_SUCCEEDED，无源码422 NO_REUSABLE_CODE，无法安全参数化422 SOURCE_NEEDS_EDIT。预览不保存、不验证、不启用；后续沿用能力库drafts → save → verifications → review（Skill）→ enabled。

## 应用共创

| 方法与路径 | 输入 | 返回/行为 |
| --- | --- | --- |
| GET `/publications` | 无 | `{items:[元信息]}`；撤回项只对作者显示 |
| POST `/publications/preview` | kind=recipe/pipeline；recipeId或agentRef，可选title、description | snapshotDigest、package、summary |
| POST `/publications` | 相同输入、snapshotDigest、confirmSharing=true | 201，不可变快照，不授予执行信任 |
| GET `/publications/{id}/export` | 无 | 发布时JSON快照；撤回后410 |
| POST `/publications/{id}/copy` | 可选dependencyBindings | 201，`{kind,recipe}`或`{kind,application}` |
| POST `/publications/{id}/withdraw` | 空对象 | 仅作者可撤回，别人404，已有副本保留 |

研究应用发布需该定义成功运行；固定应用需同一执行定义成功运行。摘要绑定实际包与发布说明，变化409 PREVIEW_CHANGED。秘密与私密引用拒绝公开；组件依赖由接收者先引入并准备。固定应用复制由内部可信参数保留publication id/digest，普通HTTP导入不能伪造权威来源。

Tool/Skill使用独立`/desktop/api/community/capabilities`协议，支持依赖事务复制、源码审阅、分页及revision，见[组件社区契约](../capability-library/社区发布设计与技术规范.md)，不可与应用发布接口互换。

## 外部开发

`GET /developer-kit`返回ZIP，包含应用样例、合成CSV、Tool/Skill包及源码、必要协议、Schema和打包工具。仅使用项目明确白名单资源，不导出当前账号数据。固定应用接口另见[应用包契约](../agent-platform/应用包与组件复用.md)。
