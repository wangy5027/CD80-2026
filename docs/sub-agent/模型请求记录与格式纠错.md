# 模型请求记录与格式纠错

更新：2026-10-14。状态：已实现，本地替身、真实WASI及隔离浏览器验证通过；真实上游本轮未调用。依据：用户确认 JSON 失败需要受控恢复，日志需要保存更具体的请求记录。证据见验收记录（本地资料，未随源码发布）。

## 用户行为

每次规划、安排下一步、代码审批和验收都保留独立模型调用记录。依据10月14日后续用户反馈，普通界面展开“模型请求记录”时只按需显示请求摘要、业务输入、输出节选和必要错误；不展示系统/开发者提示词、整份原始JSON或原始下载入口。后台本人可访问的完整诊断接口仍保留。旧任务没有保存的原文不能补造，截断片段无法安全区分业务内容时省略。展示规则见[模型请求摘要展示](模型请求摘要展示.md)，原验收保留其阶段含义。

模型返回格式错误时，仅重新请求当前阶段，反馈具体字段或解析问题，复用全任务三次纠错、32 次调用及总时限。已成功工具不重放，权限与工具预算不重置；取消、认证/连接失败与输出截断不混同格式错误。预算耗尽保留已完成步骤，并说明格式故障及此前已经记录的业务障碍。不会因格式恢复宣称任务目标已完成。

## 记录与接口

- Run.modelCalls 仅增加摘要：traceUrl、traceAvailable、errorCode、validationErrors、retryOf，以及验收阶段的最终裁定。请求正文不进入轮询快照或模型下一轮观察。
- GET `/desktop/api/sub-agent-runs/{runId}/model-calls/{callId}` 返回独立诊断 JSON；`?download=1` 返回附件。认证 owner、run 和 call 必须全部匹配，不可见时 404；响应 no-store、nosniff，附件不执行。
- 记录 schemaVersion、runId、callId、stage、model、开始/完成时间、状态、预算快照、重试关联。detail.value.request 保存实际 system/user messages、输入长度和本次时限；transport 仅白名单保存模型、JSON 模式、生成参数、HTTP 状态、上游响应 ID、finishReason、usage（上游提供时）。response 保存实际正文或失败前收到的片段、是否完整；parsed 保存成功解析的 JSON 对象（仍可能未通过阶段校验）；error 保存分类、解析位置和字段校验原因。解析位置以脱敏前原响应为准，脱敏可能改变展示文本长度。
- 不采集认证请求头、Cookie 或模型 reasoning_content。文本和结构中的凭据脱敏；保留业务请求内容供本人排障，不能当作匿名遥测。保留的正文不是逐字网络报文，脱敏及截断须明确标记。
- 每条诊断记录最多 1,048,576 字符；detail（含包装信息）最多 1,000,000 字符，超限保留首尾及偏移。originalChars/sha256 均基于脱敏后 JSON，truncated 明确是否截断，不保留凭据原文摘要。平台最终验收的理由/回答至多各 4000 字符，超限以 platformDecisionTruncated 标明。32 次调用限制同时限制每任务诊断记录数量。
- 沿用 sub-agent.sqlite3 的 records 表，以 owner + kind=model_trace + callId 保存，正文与 Run 摘要分开，不需改表。请求在发出前落盘，完成或异常时补充响应；进程崩溃时只保证已落盘部分。历史记录不回填；回退版本可忽略新增 kind。保留期随任务库，暂不新增自动清理机制。
- 服务重启恢复时，活动任务、未完成 modelCalls 及对应 model_trace 同步标为 interrupted；记录 interruptedAt 与 PROCESS_INTERRUPTED，不伪造完成时间、响应正文或上游结束原因。

## 解析与状态

复用严格 JSON 对象解析，有限兼容完整 JSON 围栏及代码字符串换行，拒绝重复键、非有限数字、多对象和猜测修复。随后按 plan/act/approve/review 检查分支必填字段、类型和动作枚举；格式错误与契约错误有独立错误码。校验通过后才能记录模型阶段成功和执行动作。

验收记录分别保留模型建议与平台最终裁定，时间线显示最终裁定，不提前写“验收通过”。本次不改变个人能力发现范围、数据覆盖或绘图库的能力身份规则。

## 验收

以临时数据库、本地模型/HTTP替身验证：后台实际请求与响应可查、失败前片段可查、按账号和任务隔离、脱敏及截断、旧记录兼容、按需加载、格式/契约错误恢复、预算耗尽、重试不重放工具、审批失败不执行、取消与时限。新版普通界面另验系统提示词隐藏、有限业务摘要和无原始下载链接；后台下载鉴权继续保留测试。前端源码变更需构建并在隔离浏览器验证。替身通过不代表真实上游通过，不用正式用户记录作为写入测试目标。
