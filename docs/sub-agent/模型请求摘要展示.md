# 模型请求摘要展示

更新：2026-10-14。依据：用户反馈“模型请求记录无需具体系统提示词，只显示请求和部分输出”。本修订覆盖普通对话界面，替代[原设计](模型请求记录与格式纠错.md)中普通界面展示和下载完整 JSON 的行为。实现已完成；本轮验证见验收记录（本地资料，未随源码发布）。

## 用户流程

- 执行过程保留每次模型调用。展开“模型请求记录”才读取详情，普通轮询、展开执行过程均不提前获取请求正文。
- 展示阶段、模型、状态、耗时、结束原因和重试关联；可查看本次业务输入与至多 3000 字符的输出节选。部分响应明确标记尚未完整返回，超限节选明确标记；没有响应不伪造输出。
- 错误代码、简短失败原因、校验说明与最终裁定仍可见。读取失败可重试，旧记录未保存时说明不可用。
- 普通界面没有完整 JSON 区块、原始请求记录下载链接或隐藏的完整正文 DOM。

## 展示边界

[modelCallPresentation.js](../../frontend/src/modules/workbench/modelCallPresentation.js)负责有界展示投影，[ModelCallDetails.vue](../../frontend/src/modules/workbench/components/ModelCallDetails.vue)只渲染投影；时间线模型行的摘要与错误同样处理。

只提取已知元数据、非 system/developer 角色的业务消息、业务上下文字段及输出。递归检查对象、数组、JSON 字符串和完整 JSON 围栏，过滤 system/developer 消息及提示字段、内部 instructions、原始请求/响应、凭据字段与模型思考字段；已知提示正文的直接回显也省略。未完整解析且带内部角色/提示字段标记的文本不直接展示。错误、parsed 回退与诊断摘要沿用相同过滤，不另开原始数据旁路。

后端 `detail.truncated=true` 的 head/tail 可能混有提示正文，界面只展示“原记录已截断”说明，不猜测片段的业务归属。业务输入最多 6000 字符、输出最多 3000 字符、各诊断说明最多 800 字符；嵌套深度和集合数量另有界限。所有文本按普通文本节点渲染，不解释输出中的 HTML。

本次不修改后端存储和诊断 API：本人认证、owner/run/call 隔离的 GET 详情及 `?download=1` 后台诊断仍保留原有脱敏记录（包括 system/user messages），不能将 UI 简化宣称为服务端删除、匿名化或 API 访问权限变更。无系统角色标记且无法与已知提示对应的自由文本无法靠前端语义判断其来源；本修订是普通界面展示约束。

## 验证方式

组件和纯函数覆盖按需加载/刷新/重试、失败状态、业务输入、部分响应、有界输出、嵌套角色/JSON 字符串、parsed/error 旁路、截断记录和时间线。隔离浏览器使用临时账号、合成数据、模型替身及真实 WASI；在所选请求响应中添加受控提示标记，核对实际 DOM 不显示它们、没有原始下载链接，并保留桌面和手机截图。受控提示标记不写入后端记录，不冒充真实上游模型请求。
