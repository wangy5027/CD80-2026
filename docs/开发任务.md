## 5. 联合验收输入与结果

规则：UTF-8（可含 BOM）、逗号 CSV、有表头；按用户明确指定的列分组，对数值列使用 Decimal 求和，分组键升序输出。预置应用对缺列、重复/空表头、不等长记录、空值、非有限或非法数值明确失败。动态应用规则由本次已确认定义决定，不冒称已对任意输入验证。

第一次输入：

```csv
category,amount
A,10
B,7
A,5
```

第一次期望产物：

```csv
category,total_amount
A,15
B,7
```

保存后第二次输入：

```csv
category,amount
A,1
C,4
C,6
```

第二次期望产物：

```csv
category,total_amount
A,1
C,10
```

## 6. 验收门槛

- 普通对话可用，主 agent 正确分流；缺参数先澄清。
- 动态路径生成工具源码和 skill；预览时工具调用数为 0、没有数据测试。
- 用户确认后实际运行刚生成的代码，模型解释上下文实际包含批准的 skill。
- 预置与动态路径均生成正确 CSV；失败保留已完成步骤和产物，说明错误位置。
- 拒绝确认、取消生成、取消执行、超时、文件变化、未知协议、跨账户访问均有明确处理。
- 额外文件未授权前不读取内容；网络、宿主密钥、进程和任意宿主文件不可访问。
- 确认重放、请求重发、页面轮询/SSE重连不会触发额外执行；重启标记中断而不重跑。
- 未保存不出现在个人应用中；明确保存后用另一个文件直接运行，定义版本不可变。
- 浏览器显示预览、运行、失败和保存状态，刷新恢复待确认项；退出账户清理界面状态。
- 后端全量测试、前端测试/构建、浏览器交互验收均提供命令与结果。

开发测试可以使用固定输入和本机模型替身；这些是开发者验证，不是产品 dry-run。真实模型验收另行运行，测试替身不能证明真实模型连通。

## 7. 当前限制与下一阶段

执行环境首期只提供 Python 标准库，不支持 pandas、pip、联网或进程；输出是平面文件。默认单工具 15 秒、内存 128 MiB、输入合计 16 MiB；整个实际运行 180 秒，单次模型生成最多 300 秒、意图识别最多 120 秒。运行记录与个人应用保存在本机。

下一阶段待办按以下顺序推进：

1. 定义量化应用的输入输出：策略代码、改写要求、标的、区间、频率、参数和回测报告格式；把写策略、改策略、回测拆成可验证能力。
2. 明确数据来源和历史数据口径，设计 pandas/数值库等依赖的隔离运行环境，继续保留输入授权与执行记录。
3. 将首个金融应用注册到现有 AgentSpec/runner 协议，补充成本、收益、回撤等结果的可核验样例及基准。
4. 持续记录真实模型的定义通过率、生成耗时和失败类型；当前严格拒绝无效定义，后续改善稳定性仍须遵守不擅自执行或自动重试的产品边界。
5. 分别澄清另外两个创新应用；部署、多用户协作、社区和多 sub-agent 并发另行立项。

上述为下一阶段建议待办，本轮未开始实现金融业务，也未配置自动交易或定时任务。
