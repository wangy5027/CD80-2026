# 平台与三个应用整合决定

日期：2026-10-14。依据：用户确认的工程 Prompt，所有实现位于最终版，三个来源目录只读。

1. 以 main-code 平台为宿主，统一身份和页面，保留各应用的原业务与持久化，不新增跨应用自动编排。
2. Explore 单一研究工作区中保留事件、关联、历史三个模块；适配公共模型与搜索，不覆盖平台公共预算或重新开启退役工具。
3. 策略应用保留独立不可变策略/执行快照与回测服务，在统一应用目录聚合入口，不强转为普通固定流程 App。
4. 应用工坊继续在原范围推荐/组合，采用原完整 AgentSpec 表示生成，再转换为 cd80.app/2 保存到平台资产库。保存不执行；验证与启用遵守现有平台准入。
5. 工坊来源索引固定当前账号、版本和摘要；可组合和可运行分开判断。修改后不能用旧定义重新取得组合资格。来源凭据、文件授权和验证不继承。
6. 独立正式空业务库与隔离验收库；公共数据与运行时按资源分类准备。Mac凭据支持不会迁移Windows加密私密记录。

接口、生命周期及验收见[整合技术规范](../integration/技术规范.md)与[功能对应表](../../整合说明与功能对应表.md)。

## 2026-10-14 用户授权的模型切换

用户在真实 GLM-5.3 多次超时后明确要求所有调用改用 GLM-5.3-flash。最终版使用已验证供应商型号 ID `GLM-5.3-Flash`：主站聊天、统一 App/Tool/Skill 创作、子任务、固定流程解释、策略工坊、应用工坊及 Explore 新研究均采用此型号。配置模板、默认值、页面默认标识同步修改；三个只读来源目录不变。

不改写此前研究或应用的模型/验证证据，不把旧模型验证结论自动转移到新配置；受模型配置约束的资产必须按平台规则重新验证。Explore 保留旧历史的冻结型号并明确拒绝以停用型号续跑，引导新建研究。原模型失败报告保留，新型号的真实验收另外记录。超时、预算、数据与启用条件不放宽。
