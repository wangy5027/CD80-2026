# 本地金融能力迁移与通用协议

状态：产品范围已确认，工程契约已实现并随26包发布。日期：2026-10-13。

## 背景

本地13份sfc Skill仍依赖南财工具；首批4 Tool/5 Skill只完成有限本地替代。用户确认将现有包完善、更多本地数据接入、适合sub-agent的通用协议扩展合并为本次迁移项目，不继续逐字段访谈。

## 决定

金融逻辑留在可复用包中；平台提供通用有界读取、覆盖、错误、预算、取消和工件协议，不引入逐金融handler、任意SQL或任意网络。复用sub-agent任务、授权和存储，不另建金融调度器。

历史行情支持股票/ETF/指数不复权日周月线；公告和两融证券必填。历史/公告南财旧版删除，旧引用必须迁移重新确认，历史记录保留。其他旧版按实际替代覆盖评估，不将本决定当作全部删除授权。

第四组缺数据能力（研报、完整主题、实时行情、公告正文、历史新闻等）不纳入本轮；通用聚合不扩大成全市场两融榜单。新闻沿用已确认外部例外。此前首批规则仅在本目录明确增量范围内被更新，不倒改历史验收。

## 影响与依据

涉及能力库Schema/OpenAPI、受控连接、数据服务、包构建、sub-agent适配及前端结果说明。已完成代码迁移和服务部署，未修改原始业务数据。验证与限制见发布记录（本地资料，未随源码发布）。详细用户决策及工程默认值分离记录在[迁移项目](../local-financial-capabilities/migration/README.md)。沿用[0002包内业务边界](0002-本地金融可插拔能力.md)及[0003子任务职责](0003-主对话子agent执行.md)。
