## 接入范围

沿用所提供网站的 Vue 3、Flask、现有登录系统及 `/desktop/api` 封装。新增 `/desktop/api/financial-data` 后端代理、`financialDataApi.js` 前端调用模块和侧栏“数据管理”页面。页面浏览、筛选、分页、详情和 CRUD 均调用同源接口；前端依据能力接口展示维护入口，写权限仍由后端校验。页面验收见网站 `docs/数据管理页面验收.md`。

原 ZIP 保持原样。接入版源码不包含原 `.env`、用户账户/聊天数据库或 WASI 运行缓存；本次也未调用真实模型服务。完整网站测试尝试中，原有 `test_agent_executor` 因未安装 `data/agent-runtime/manifest.json` 所指 WASI 运行时而不能初始化；该执行器不属于本次数据接口改动。需要模型生成与隔离执行功能时，依照网站原手册配置模型并安装运行时。

数据 API 默认只监听 127.0.0.1:8895，接入版网站默认 127.0.0.1:8896。当前已有的 8893 服务未被停止或修改。没有进行公网部署。
