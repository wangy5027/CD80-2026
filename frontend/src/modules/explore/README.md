# Explore 前端模块

本模块从应用1交付快照接入最终版；平台导航、账号和共享 API 由最终版宿主提供，接入契约见 [Explore 接入记录](../../../../docs/integration/Explore接入.md)。下文历史验收文件路径属于来源项目，不作为最终版验收结果。

Explore 使用局部蓝紫流光玻璃主题，只作用于 `.explore-theme`、独立输入组件与本模块抽屉。`ExploreAmbientBackground.vue` 常驻根节点，不随状态或模型结果重新挂载。`useExploreMotion.js` 提供默认开启的“动态效果”偏好；手动关闭、系统减少动态效果或标签页隐藏时暂停装饰，不影响研究状态更新。报告页首离开阅读视口后暂停自身边缘光。没有复制其他产品字体或加入新动画依赖。

`ExploreComposer.vue` 始终保留同一个 textarea；使用冰蓝紫玻璃外壳、边缘流光、聚焦反馈、按实际按钮测量的模块滑块，以及服务端或真实文件选择变化触发的标签过渡。输入高度随内容与可见视口局部调整，测量时保留内部滚动；中文组合输入不会误发送。报告与输入底部槽共用同一列宽；文件与来源抽屉覆盖右侧，不推挤其中任一列。自动/自选设置移入参考材料抽屉，输入区只保留来源标签、文本和一行主要工具。

报告直接展示模块、结果状态、标题与信息截止时间，核心发现、重要不确定性和信息缺口提前；原始问题、确认问题与创建时间保留在研究详情，发生澄清时页首可见提示。实时阶段主视图只保留最近三条真实事件，完整过程可展开。报告落位只由本页观察到的运行转成报告触发，刷新已有报告不补播成功动画；同一记录轮询不会重置滚动。用户在本页切回旧记录时恢复已记录的阅读位置。引用打开右侧来源抽屉并定位对应保存文本；关闭抽屉恢复焦点。会话行菜单沿用独立重命名/删除窗口，顶栏标题另提供原位编辑。

`ExplorePanel.vue` 是工作台内独立的研究页，入口为首页 Explore 卡片，地址为 `/desktop/#explore`。选中的会话与运行记录保存在地址的 `session`、`run` 参数中，可直接打开、刷新或通过浏览器前进后退恢复。离开 Explore 后沿用原工作台页面切换；本模块不会向普通聊天发送研究提示词。

`useExplore.js` 管理页面状态与只读轮询。`api.js` 使用现有同源 `/desktop/api` 和登录 Cookie 调用 Explore 后端。研究会话、问题、状态、报告、来源和分支均以服务端记录为准；浏览器 `sessionStorage` 按请求签名暂存网络失败后重试所需的幂等标识，不保存研究结果；存储不可用时当前页面内仍保留标识。成功只清除对应请求，其他分支未完成的请求可继续沿用原标识。刷新只发 GET；取消、重试和重新生成分别由明确按钮触发。切换会话加载期间禁止提交，组件卸载和切换记录后，旧响应或失败提示不更新新页面。

三个模块创建运行后先检索资料并检查研究意图。运行进入 `awaiting_clarification` 时，页面展示服务端基于材料提出的澄清问题和三个候选方向；点击候选直接以 `option_id` 调用 `/runs/:id/clarify`，选定方向重新检索后直接生成报告；自定义需求通过单独编辑框以 `question` 提交，服务端重新判断意图，明确后自动生成报告，仍不明确时继续等待澄清。新的明确问题无需二次材料确认。旧 `awaiting_review` 记录仍可手动调用 `/runs/:id/confirm` 完成，不由刷新自动执行。旧 `awaiting_input` 判断确认记录也保持可用。澄清和兼容确认的网络重试保留各自幂等标识；导航到其他记录后，迟到响应不会覆盖当前记录。

材料抽屉在运行保存材料后即可打开，显示来源类型、安全原始链接、发布时间、检索时间与 `text_used` 的完整换行文本；`search_snippet` 与 `news_excerpt` 被明确标为摘要或摘录而非全文。旧 `awaiting_review` 阶段可勾选来源；报告阶段按服务端 `confirmed_sources` 只读展示已用材料。材料和澄清内容使用 Vue 文本插值，不解释 HTML。旧运行没有 `materials` 或 `retrieval` 时按无记录处理。

每个探索会话有一个跨三个模块共享的服务端文件池，文件包括实际保存的搜索摘要、快讯摘录、用户材料和报告。文件池抽屉可查看纯文本正文及安全原始链接、下载、重命名和移除；移除文件会更新未来的模块偏好，已完成运行的上下文快照保持原样。参考材料抽屉的“自动 / 自选”控件按模块独立保存：自动模式预览当前来源报告分支及必要祖先的文件，自选模式最多勾选 8 个本会话文件。运行提交时传入当前模块的 `context_mode` 和 `file_ids`，服务端冻结实际使用文本、字数与截断限制；运行详情展示这份快照。刷新仅重新读取文件池、模块偏好、运行记录与预览，不会自动提交分析。

研究历史在桌面默认常驻，可由用户隐藏；选择会话、旧报告或分支不会自动关闭。每条会话的“⋯”菜单可直接重命名或删除该会话，无需先切换到它；重命名和删除均在独立确认窗口内完成，删除前会展示目标名称与不可恢复的后果。窄屏沿用可人工开合的抽屉，只有抽屉作为模态层打开时才约束焦点并隔离主页面。右上角文件池持续显示当前会话文件总数；真实新增文件更新徽标与轻提示，用户可展开名称列表或打开抽屉查看，不改变报告与输入列宽。旧会话初次载入的存量文件不会误标为新增。运行轮询会读取服务端新增文件，无需等报告完成。材料抽屉是独立模态层，长材料文本可聚焦并用键盘滚动。报告后的推荐问题按钮直接创建新的研究运行，示例问题按钮仍只填入输入框。

`model.js` 负责模块文案、地址、分支树及可打开来源 URL 的安全检查。报告按结构化字段显示；自由文本借用工作台 `pages/format.js` 中转义 HTML 的 Markdown 格式器，不执行模型输出的 HTML，也不把模型生成的链接直接渲染为可点击外链。来源区只开放经过协议和主机检查的真实来源 URL。

输入主题或问题后，Explore 由服务端主动使用现有网页搜索与 AkShare 快讯查找材料；明确的问题自动生成报告，模糊问题显示候选方向或自定义补充入口。链接作为检索线索，不保证已读取全文；全文不可得时提示用户粘贴原文。运行中与报告后的 `retrieval.searches` 展示实际查询词、时间范围、搜索时间、结果数量及空结果或失败状态；来源按 `kind` 区分网页搜索、新闻快讯和用户材料。旧报告没有 `retrieval` 时明确说明未保存搜索过程，不补造记录。发布时间未知按“未知”显示，不以搜索时间替代。搜索记录与模型结论均不是事实已验证的证明。

本轮不包含长期知识画像、解释深度版本、复杂关系图、严格历史时点验证、行情回测、投资效果评估或专业分析正确性评分。历史报告显示服务端提供的定性对照与证据不足说明，不展示未经验证的收益率。


第二轮材料与动态交互的截图、操作录屏、性能记录和测试边界见 `docs/Explore-流光玻璃-V2-验收.md`。任务书中的推荐仅填入建议与已明确的用户要求冲突，本轮继续保留推荐点击直接执行并生成新分支的行为。

第三轮去掉 textarea 的第二层卡片与焦点环，研究/报告场景预留稳定的来源槽。提交只对已清空的输入外壳做位移，输入、组合输入和暂停动效会立即取消位移；完成仅让页首与前三块内容短暂落位，不对整篇长报告重播动画。

短结论使用紧凑的核心发现与默认展开的边界区；限制和方法说明保持原文，低优先级的完整检索过程与文件快照可以展开。运行主视图展示真实阶段、已取得的材料和最多三条公开活动；字符数与完整公开过程放入详情。`presentation.js` 只投影允许展示的工具/模型元数据，不显示参数、原始错误或内部报文；只有明确的 claim/source 映射才能展示引用片段，研究记录中的关联主张不等于已写入报告的结论。来源抽屉区分报告保存的使用文本与检索时保存的材料。

新增文件提示在 2.8 秒后收起，悬停、键盘聚焦或展开时保留；文件总数与新增摘要留在文件池。报告完成后，仅当下一题仍沿原始来源时自动接续新报告，用户运行期间已清除或改选的来源不会被覆盖。日级日期不补时分；已知时区的时间转为 UTC+8 展示，原始值与数据不修改。

第三轮的 D01—D08、U01—U20、截图、录屏、真实性边界及性能原始记录见 `docs/Explore-UI-V3-验收.md`。新增测试 `tests/browser_explore_ui_v3.mjs`，真实烟测入口 `scripts/smoke_explore_ui_v3_live.py`；浏览器合成替身的通过不代表真实研究工具链通过。

后续按用户反馈精简页面：页首不再展示信息截止、AI 生成/保存标记、研究详情及已结束的研究过程；移除动效开关与输入框上的来源报告行。服务端时间、报告分支和上下文保持原数据，运行中的阶段与取消仍显示。

`ExploreSourceChip.vue` 将正文、时间线、关系与历史案例的引用合并为紧凑行尾胶囊：一个本地图标与“来源”，额外来源显示 `+N`。计数只包含去重后可映射的来源，未知引用保留“来源待核对”提示。点击先显示该段关联的全部来源，可切回全部材料；关闭后恢复引用按钮焦点。正文仍通过现有安全格式器渲染，没有插入模型 HTML 或请求外部站点图标。桌面与手机引用验收见 `tests/browser_explore_citations.mjs`，截图与原始结果在 `data/explore-citations/`，均明确使用测试替身。
